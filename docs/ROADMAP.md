# TAAS 로드맵

딘이 배운 프로그램들(아티산·크롭스터/기센·파이어스코프·이카와)의 기능을 TAAS에 하나씩 붙여가는 계획.
✅ = 지금 들어 있음 · ⬜ = 아직

## 0단계 — 판단 엔진 (완료)
- ✅ 로스팅 노트 53개 → 규칙 모음 (`knowledge/`)
- ✅ 실시간 경고: 하강 중 감압·큰 폭 감압 / 수분 와장창 / 1차 히트 배리어 / Aero Accel 단계 (`taas_rules/`)
- ✅ 숫자 기준은 `taas_rules/config.json` 한 곳에서 조정

## 1단계 — 온도 입력
- ✅ 입력 장치를 갈아끼우는 구조 (`app/sources.py`)
- ✅ 가상 로스터: 이지스터 1.8 1.2kg 기록에 맞춘 연습용 (TP 1:16 / 94℃, 1차 약 10분)
- ⬜ 실제 이지스터 1.8 연결: 열전대 2개(BT·ET) → USB 온도 모듈 → `HardwareRoaster.read()` 구현
  - 모듈 기종은 로스터 설치 때 결정 (아티산이 지원하는 기종을 고르면 참고 코드가 많음)
- ⬜ 화력·배기 값을 기계에서 자동으로 읽을 수 있는지 확인 (안 되면 지금처럼 버튼 기록)

## 2단계 — 실시간 화면 (완료, 계속 다듬기)
- ✅ BT·ET·BT RoR·ET RoR 그래프 (RoR은 15초 회귀 기울기) — 아티산·크롭스터
- ✅ 투입·옐로·1차·1차 끝·2차·배출 버튼, TP·1차 자동 표시 — 아티산
- ✅ 화력·배기·드럼 −/+ 버튼과 직접 입력, 그래프에 조작 기록 — 크롭스터·파이어스코프
- ✅ 감압 전에 경고 확인창 ("그래도 적용"은 기록 남음)
- ✅ 경고 소리 (경고 3번·제안 1번·1차 2번)
- ✅ 기준 배치 겹쳐 보기 — 크롭스터 레퍼런스·파이어스코프 오버레이
- ✅ 건조 / 메일라드 / 디벨롭 비율, 디벨롭 시간·DTR — 크롭스터
- ✅ 배출 후 결과 입력 (배출량 → 손실률, 홀빈·분쇄 색도, 컵 메모)
- ✅ 배출하면 BBP 쿨다운 자동 전환 + 경과 시간 표시
- ⬜ 1차 예측 시계 ("1차까지 약 40초") — 크롭스터 예측
- ⬜ 기준 배치와의 차이 숫자 (같은 시간 대비 BT ±℃, RoR ±) — 파이어스코프
- ⬜ 단축키 (아티산처럼)
- ⬜ 화면 확대 모드 (멀리서도 보이게)

## 3단계 — 배치 기록·생두 관리
- ✅ 배치마다 JSON 저장 (`batches/`)
- ⬜ 생두 정보 화면: 산지·가공·밀도·수분·스크린·소프트포인트 (20·22번) → 출발 레시피 자동 제안 (17·52번)
- ⬜ BBP 테스트 모드 (45번 시트: 투입 −10℃ → −20℃로 쿨다운 온도 찾기)
- ⬜ 환경 기록: 실내 온습도·외기·생두 수분 (32·44번 — 제주 습도 판정용)
- ⬜ 배치 목록·검색·태그 — 크롭스터·파이어스코프
- ⬜ 아티산 파일(.alog) 가져오기 — 예전 기록 옮기기

## 4단계 — 비교·처방 (TAAS만의 부분)
- ⬜ 같은 랏 배치 비교: TP → 곡선 → 색도·손실률 3단계 판정 (25번)
- ⬜ 다크 로스팅 스윙바이 진단 (29·42번)
- ⬜ 다음 배치 처방: "변수 하나만" 바꾸는 제안 (05·12·38번)
- ⬜ 로스트 플랜(CVA 항목 예측) vs 커핑 결과 일치율 (15번)
- ⬜ 블렌드 도우미: 선/후블렌딩 경고 (20번)
- ⬜ Gear Shift(가변 드럼) 트리거 제안 (21번) — 딘 머신 RPM 가변 확인 후

## 5단계 — 이카와식 프로파일 재생 (나중)
- ⬜ 저장한 배치를 "목표 곡선"으로 따라가기: 지금 BT가 목표보다 앞서면/뒤처지면 알림
- ⬜ 자동 화력 제어는 이지스터가 외부 제어를 받는지 확인 후 (안전 문제로 가장 마지막)
