# 로스팅과 메일라드 단계에 대한 생각 — "메일라드를 늘리면 더 맛있나?" (주성현)

## 1. 질문: "메일라드 단계를 연장하면 더 좋은 맛이 나나요?"
- 많은 로스터가 이 단계를 길게 가져가면 좋은 결과가 나올 거라 믿는 경향 → 글쓴이는 **반드시 그렇지 않다**는 입장

## 2. 메일라드 반응의 기초
- 단백질(아미노산)과 당이 반응해 복잡한 화합물을 생성. **온도와 시간**의 영향을 크게 받고, **온도가 높을수록 반응 속도가 빨라짐**
- 결과는 단순히 시간이 길어질수록 더 많이 생성되지 않음 → **선형적이지 않음**
- 오히려 시간이 길어지면 **열이 제대로 전달되지 못하거나, 필요 이상의 열이 공급**될 수 있음
- 로스터에게 필요한 능력: 특정 요소의 변화를 배치마다 시도하고 그 변화가 맛에 어떤 영향을 미치는지 알아내는 **탐구심과 인내심**
- 흔한 오류: 한 가지 요소(낮은 가스, 낮은 ET, 긴 메일라드, 긴 로스팅 시간)가 전체 맛을 이끌었다고 결론 → 그런 결론엔 수많은 반복 실험과 다양한 환경 테스트가 필요 (✅ 05 "변수 하나씩", 21 A/B 테스트)

## 3. 메일라드 단계를 연장하는 방법의 문제점
### ① RoR 감소 → 크래시 위험
- 메일라드를 연장하려면 RoR이 낮아지고 평탄해짐 → **1차 크랙까지 더 낮은 RoR**로 도달
- RoR이 너무 낮아지면 **RoR 큰 폭 하락(크래시)** 위험↑ → 곡선 불안정, 예측 가능성↓
- 연장 방법은 대부분 **시작부터 약한 열** 또는 **메일라드 시작 시점이나 그 이전에 열을 큰 폭으로 감소**
- ✅ 12 라오 "베이크드 = RoR 크래시", 05 케냐 "전반 열 부족 → 1차 크래시 → 베이크드", 11 주성현 "투입~140~150℃까지 최대 열", 23 블랙다이아몬드 "약 163℃까지 가스 최대 유지"

### ② 반응 속도 감소
- 메일라드를 두 배로 늘린다고 그만큼 더 많은 화학 반응이 일어나지 않음
- 반응 속도는 시간이 늘어날수록 오히려 줄어들 수 있고, 생성물의 양은 **비선형**일 가능성이 큼

### ③ 시간이 다른 로스트가 같은 결과를 낼 수 있음
- **7분짜리와 13분짜리 로스팅이 거의 동일한 맛**을 낼 수 있음 → "메일라드 연장 = 항상 더 좋음"을 부정
- 커피마다, 로스팅 포인트마다, 배치 크기마다 진행은 다르지만 비슷한 결과를 만들 수 있다는 건 대부분의 로스터가 아는 사실
- ✅ 25 노트 "같은 커피, 다른 하루: 시간 27초 차이에도 결과 동일", 12 라오 "정답 시간은 없다"

### ④ 균형의 문제
- 메일라드를 너무 길게 가져가면 다른 중요한 단계에 영향을 미쳐 **전체 균형이 깨짐** → 맛의 일관성·예측 가능성 희생
- 로스팅을 계획할 땐 **특정 단계가 아니라 그 배치의 전체 단계**를 봐야 함

### ⑤ RoR의 영향과 실험적 증명
- RoR을 낮추고 메일라드를 확장했을 때 1차 팝까지의 온도·시간이 어떻게 변하고 맛의 차이가 어떻게 나는지 → 실험 데이터로 확인 가능

### ⑥ 메일라드의 최적 지점
- 모든 로스팅에는 최적의 중간 지점이 있음. **원산지·가공 방식·품종**에 따라 적절한 메일라드 길이가 다름 (✅ 04 스트렝스 레벨, 22 소프트포인트, 19 발아 대사)

### ⑦ 스테이크 비유
- 스테이크를 구울 때 메일라드를 지나치게 연장하면 고기의 질감과 맛이 망가짐 → 커피도 메일라드를 지나치게 길게 가져가면 원두 맛의 균형이 깨짐

## 4. 결론
- 로스팅엔 **적절한 균형**이 중요. 메일라드를 단순히 길게 가져가는 것은 좋은 로스팅을 보장하지 않음
- 각 원두와 로스팅 환경에 맞춘 **적절한 균형과 중간 지점**을 찾는 것이 가장 중요

## 프로파일 설계 규칙 (딘 적용용)
1. **메일라드 시간 자체를 목표로 잡지 않는다.** 목표는 컵(로스트 플랜, 15 노트)이고, 메일라드 길이는 결과값
2. 메일라드를 늘리고 싶을 때 **"초반 화력을 약하게" 또는 "메일라드 시작 전 큰 폭 감압"으로 늘리지 않는다** → 1차 RoR이 낮아져 크래시 위험
   - 늘려야 한다면: 투입온도·배치량(35 노트 "배치 500g~1kg 추가로 느리게") 또는 배기 단계(Aero Accel)로 **RoR 하강을 완만하게 유지한 채** 늘리기
3. 계획은 **전체 단계 비율**(건조 / 메일라드 / 디벨롭)로 본다. 한 단계만 늘리면 다른 단계가 줄어 균형이 깨짐
4. **1차 진입 RoR을 지킨다** — 1차 직전 RoR이 머신 기준보다 낮거나 1차 직후 급락하면 그 배치는 메일라드 연장 실패 신호
5. 같은 맛이 7분에도 13분에도 날 수 있다 → **시간이 아니라 결과 지표(색도·손실률·컵)**로 판정 (25 노트)
6. 메일라드 길이의 기준은 **생두별**(원산지·가공·품종) → 생두 기록에 "최적 메일라드 비율"을 결과로 쌓기
7. 변화를 시도할 땐 **변수 하나만**, 같은 조건 A/B로

## 프로그램 규칙 (TAAS 연동용)
```
[단계 비율 표시]
- 건조(투입~옐로) / 메일라드(옐로~1차) / 디벨롭(1차~배출) 시간과 % 자동 계산
- 같은 생두 과거 최고 배치의 단계 비율과 비교 표시

[메일라드 연장 시도 감지]
- 메일라드 % 가 기준 대비 +5%p 이상 AND (초반 가스 기준보다 낮음 OR 옐로 전후 감압 폭 큼)
  → 경고 "약한 열로 메일라드 연장: 1차 RoR 저하·크래시 위험"
- 1차 진입 BT RoR < 머신 기준값 OR 1차 후 30초 RoR 하락폭 > 임계 → "크래시: 이전 구간 열 부족" (12·05)

[대안 제안]
- 메일라드를 늘리고 싶다 입력 시 → ①배치량 +, ②투입온도 −(+가스 보강), ③배기 단계 조정 순으로 제안, "초반 가스↓"는 제안하지 않음

[판정]
- 품질 판정은 시간·단계 길이가 아니라 색도·손실률·컵 점수로 (25 노트 모드와 연동)
```
- ⚠️ +5%p·RoR 기준값은 Claude 출발값 → 딘 데이터로 조정
