## 1. 왜 열 안정성이 중요한가
- 좋은 커피는 일관성에서 시작하고, 그 출발점은 **정밀하게 제어 가능한 열 운용**. 열 정밀성은 있으면 좋은 요소가 아니라 커피 향미를 지탱하는 기초
- 라이트의 과일 향미·섬세한 단맛, 다크의 데미지 없는 깨끗한 묵직함·초콜릿 → 결국 핵심은 **로스팅 환경 속 열을 어떻게 다루느냐**, 그 중심이 대류열과 공기 흐름(에어플로)
- 미세한 온도 변동이 컵을 무너뜨림
  - 열 공급 **부족** → 덜 익은 떫은맛, 날카로운 신맛
  - 순간적인 열 **과잉** → 데미지, 쓴맛·탄맛, 고유 캐릭터 소실
- 같은 세팅이어도 변수가 늘 존재: **이전 배치의 잔열, 버너의 지연 반응, 팬 스피드의 미세한 차이** → 일관된 열 흐름(thermal flow) 확보가 배치 간 재현성의 핵심 (✅ 25 노트 "같은 커피, 다른 하루", 12 BBP)
- 대류 중심 로스터는 열 변화에 빠르게 반응하고 공기로 균일한 열 분포 → 로스터가 의도한 방향으로 공급 열량을 정확히 컨트롤 가능

## 2. 열 전달 방식과 에어플로
- **전도열**: 드럼 벽과의 직접 접촉. 내부에서 꾸준히 열을 만들지만 고르게 전달하기 어렵고, **적극적 열전달·조절에 한계**
- **대류열**: 뜨거운 공기가 움직이며 전달. 대류 중심 로스터의 핵심. **에어플로는 곧 열 공급과 직결** → 조정하며 실시간으로 로스팅 환경을 형성
- **ETeRR**은 이 대류열 운용과 깊이 연결: ET의 반응성을 기반으로 공급 열량을 분석·조정 → 단순히 공기를 세게 틀고 끄는 수준을 넘어선 정밀 로스팅
- ✅ 01 Prequel 전도열 "프라이팬: 편차·표면 캐러멜화↑", 18 "전도열 중심 환경은 겉만 익고 속은 안 익음"

## 3. 에어플로가 컵에 미치는 영향
### ① 향미 발달 (마이야르·캐러멜 구간의 열 전달 관리)
| 에어플로 | 결과 |
|---|---|
| 너무 느리면 | 열 분포가 불균일 → **플랫하거나 베이크드** |
| 너무 빠르면 | 수분이 지나치게 빨리 증발 → 화학 반응이 충분히 안 일어남 → **단맛·깊이 부족** |
| 균형 | 열을 고르게 → 복합 당이 천천히 분해 → **바디·단맛·여운** |
- Aero Accel을 결합하면 특정 구간에서 열 공급량을 가속·감속해 원하는 단맛·산미·클린컵을 정밀하게 설계
- ⚠️ "느린 에어플로 → 베이크드"는 열 분포 불균일 관점. 12 라오는 베이크드 원인을 RoR 크래시로 봄 → 둘 다 "열 흐름이 꺾임"으로 수렴

### ② 배치 간 일관성
- 강하고 안정적인 에어플로는 내부 환경을 일정하게 유지 → **국소적 과열·언더디벨롭 감소** → 예측 가능한 프로파일
- ETeRR 방식으로 ET 곡선을 모니터링하면 다른 날, 다른 배치에서도 높은 재현성 (✅ 25)

### ③ 클린컵
| 에어플로 | 결과 |
|---|---|
| 너무 느리면 | 연기·가스·은피가 챔버에 머물며 원두 표면에 다시 달라붙어 **잡미·스모키** |
| 적절하면 | 부산물이 신속히 제거 → **맑고 달콤하며 선명한 마무리** |
- ✅ 12 라오 "배출 때 연기·채프가 많이 쏟아지면 풍량 부족", 그래피티 "후반 풍량↓ = 향↑ 클린컵↓"

## 4. 에어플로 관리 실전 팁 (Aero Accel)
| 단계 | 운용 | 이유 |
|---|---|---|
| **초기** | 에어플로를 **낮거나 중간**으로 유지 | 과도하면 초반 커피 표면이 말라버려 이후 내부 열전달에 문제 (✅ 22 박싱) |
| **본격 열 전달** | **점진적으로 높여** 균일한 갈변 지원 | 이 시기의 균형이 향미 복잡성에 직결 |
| **가속 (1차 팝 이후)** | **강한 에어플로**로 내부 압력 관리, 연기·은피·휘발 성분 제거 | **클린컵의 핵심 구간**, 후반 과도한 열량 공급 방지 |
| 모니터링 | ET 센서로 에어플로 반응을 즉시 확인 | |
- ✅ 23 노트 실제 수치: 15Pa → (TP) 35 → (약 153℃) 50 → (1차) 60Pa / 25 노트: 20 → 30 → 55 → 65% / 03 노트: 20% → 점진 → 1차 60%

## 5. 흔한 실수
1. **초반부터 과도한 에어플로** → 표면이 말라 내부 열전달 문제
2. **조정 생략** → 배치마다 다른 결과
3. **티핑·스코칭을 에어플로로만 해결하려 함** → 먼저 **투입온도·배치량** 등 다른 조건 점검 (✅ 20 노트 "대증요법 금지", 02 "스코칭은 드럼·화력·투입온도 조합")

## 6. 결론 — ETeRR + Aero Accel로 완성하는 열·공기 운용
1. 균형 잡힌 열 전달 → 향미 발달과 단맛 극대화
2. 안정적인 환경 유지 → 배치 간 일관성
3. 부산물 배출 → 깨끗하고 선명한 컵
4. ETeRR → ET 기반 정밀 분석과 열 운용 전략
5. Aero Accel → 순간 열량 제어로 프로파일 완성도 향상
- 대류열과 에어플로 관리의 마스터링은 곧 최고의 로스팅을 위한 열쇠. 로스터가 공기를 어떻게 다루는지에 따라 섬세한 표현력과 재현 가능한 특별함이 결정됨

## 프로그램 규칙 (TAAS 연동용)
```
[Aero Accel 단계 점검]
- phase=초기(투입~TP): exhaust > 머신 중간값 → "표면 선건조 위험"
- phase=본격 열전달(TP~1차): exhaust가 한 번도 오르지 않음 → "단계 상승 누락: 갈변 불균일 가능"
- phase=1차 이후: exhaust 상승 없음 → "클린컵 위험: 연기·은피 재부착"

[컵 → 에어플로 원인 후보]
- 잡미·스모키 → 1차 후 배기 부족
- 플랫·베이크드 → 중반 에어플로 부족 또는 RoR 크래시(12)
- 단맛·깊이 부족 + 빠른 진행 → 에어플로 과다(수분 급증발)

[대증요법 방지]
- 티핑·스코칭 입력 시 → 배기 조정 제안 전에 투입온도·배치량·드럼 rpm 점검 체크리스트 먼저 표시
```
