# 2차 팝에서 드러나는 열 운용의 진실 — 다크 로스팅 RoR 비교 (주성현)

- 출처 [BL11]: 네이버 블로그 "로스팅패스파인더"(주성현) 2025-05-22, "2차 팝에서 드러나는 열 운용의 진실 — 빈 ROR 곡선 하나로 읽는 커피의 상태 보고서". 딘 제공 캡처 4장
- 주제: **다크 로스팅**에서 1차 이후~2차 팝까지의 BT RoR로 열 운용을 진단
- 그래프 판독 🔍 (머신·생두·투입 조건 미기재, "같은 생두, 비슷한 로스팅 시간"으로만 설명)

신뢰도: ✅ 기존 노트와 일치 · ⚠️ 글쓴이 단독 · 🔍 판독 불확실

## 1. 전제
- 로스팅의 핵심은 **'언제', '얼마나', '어떻게'** 조절하느냐 → 같은 생두라도 열을 다루는 방식에 따라 완전히 다른 향미
- 그중 **2차 팝 시점의 BT RoR**은 로스팅 전반의 열 운용이 얼마나 정확했는지를 판단하는 중요한 지표

## 2. 두 프로파일 비교
| 항목 | 프로파일 A (좋음) | 프로파일 B (나쁨) |
|---|---|---|
| 1차 시작 | 8:40 / 206.1℃ | 7:30 / 201.8℃ |
| 1차 끝 | 9:46 / 214.7℃ | 8:32 / 211.4℃ |
| 2차 시작 | 11:27 / 230.4℃ | 10:10 / 229.5℃ |
| 배출 | 236.2℃ (약 12:11 🔍) | 약 23x.7℃ (약 10:55 🔍) |
| DT / DTR | 3:31 / 28.8% | 3:25 / 31.3% |
| 1차 후 RoR | **부드럽게 하강** | 하강 후 다시 상승 |
| 1차 끝 직후 | **스윙바이(Swing By)** 발생 | 스윙바이는 A와 동일하게 발생 |
| 스윙바이 이후 | 2차까지 **자연스럽게 하강**, 안정적 곡선 | **하강 없이 고점 유지** → 2차에서 고온 상태로 배출 |
| 해석 | 열 공급·배기 조절이 적절한 구조적 흐름. 불필요한 열 공급이 없어 원두 조직에 무리가 없음 | 초중반 과도한 열 공급 또는 이후 열 제어 실패 |
| 컵 | 다크인데도 **향미 손실 없이 섬세하고 깨끗한 뉘앙스** | 조직 손상·과탄화·필요 이상의 쓴맛 → 향미 손실 |
- **스윙바이(Swing By)**: 1차 팝 종료 직후 RoR이 한 번 꺼졌다가 다시 살짝 올라오는 구간 (11 노트 주성현 "다크는 스윙바이를 잘 만들어서 낮은 열량으로도 BT가 충분히 상승하게"의 바로 그 현상)
  - 핵심은 **스윙바이 이후의 방향**: 다시 하강하면 좋음(A), 고점을 유지·상승하면 과열(B)

## 3. 왜 2차 팝 시점의 RoR이 중요한가
- 2차 팝은 원두 내부 수분이 거의 다 사라지고 **세포 조직이 극도로 약해진 상태**에서 발생
- 이 민감한 시점에 RoR이 하강하지 않고 유지·상승하면
  1. 과도한 열 공급 → **원두 구조 손상**
  2. 화학 반응 과속화 → **복합성 상실, 평면적이고 거친 맛**
  3. 표면 탄화 + 내부 건조 불균형 → **텁텁함, 스모키함, 불쾌한 쓴맛**
- 이건 단지 "그 순간의 화력 문제"가 아니라 **로스팅 전반의 열 운용이 과도했거나 설계가 부정확했다는 신호**

## 4. 해결: ETeRR이 말하는 전 과정의 열 밸런스
- **2차 팝 직전에 화력을 줄인다고 해결되지 않음** → 그 순간의 RoR 곡선은 이미 이전 구간에서 **누적된 열 에너지의 결과**
- 필요한 것은 전 과정에 걸친 정밀한 열 운용 설계
  1. 초반부터 **필요 이상으로 열을 밀어붙이지 않기**
  2. 로스팅 전반의 **에너지 잔존량(드럼·환경에 쌓인 열)**을 고려한 화력·배기 조절
  3. 배출까지 이어지는 흐름 속에서 **RoR이 자연스럽게 하강하는 곡선** 확보
- 좋은 로스팅은 **마지막 1~2℃의 온도 조작**으로 결정되지 않음. 그 온도에 도달하는 흐름 전체에서 열을 어떻게 조절해 왔느냐가 핵심

## 5. 곡선 하나가 말해주는 것
- 2차 팝에서 RoR이 **부드럽게 하강** → 설계가 잘 된 열 운용, 향미 손실 없이 완성
- 2차 팝에서 RoR이 **정체되거나 오히려 상승** → 과도한 열 축적, 향미 파괴 가능성 높은 구조
- "2차 팝에서의 RoR 곡선은, 그동안 당신이 열을 얼마나 정확하게 다뤄왔는지를 보여준다"
- 로스팅은 일회적인 컨트롤이 아니라 **전체 흐름을 설계하는 일**

## 기존 노트와의 관계
- ✅ **12 스캇 라오 "플릭"**: B는 1차 이후 RoR이 다시 올라 2차까지 유지 = 다크 로스팅판 플릭. 라오 "플릭은 환경 과열이 원인, 로스티한 맛" ↔ 이 글 "과탄화·쓴맛"
- ✅ **02·10 축열**: "드럼은 가스를 줄여도 바로 안 식는다", "후반 복사열 잔존 = 쓴맛" ↔ 이 글 "에너지 잔존량 고려", "2차 직전 화력을 줄여도 해결 안 됨"
- ✅ **12 라오 "크래시를 1차에서 열을 더 넣어 막지 말 것"** 과 대칭: 플릭도 그 순간이 아니라 이전 구간(초중반)에서 고쳐야 함
- ✅ **21 Gear Shift "다크: 1차 종료 신호에서 추가 감속"**: 스윙바이 이후 RoR이 다시 오르는 걸 드럼 감속으로 막는 수단
- ✅ **11 주성현 다크**: 투입↑·가스↓·배기↓·투입량↓ 세팅 + 스윙바이 관리
- ✅ **01 [180]**: 다크 = 작은 대류·높은 온도·화력 작게
- DTR 28~31%: 다크에선 라오 기준(20~25%)보다 높게 형성되는 것이 자연스러움 (24 노트 머신별 DTR과 별개로 로스트 레벨 효과)

## 딘 이지스터 1.8 다크 로스팅 체크
- 세팅 출발: 11 노트 다크(800g / 투입 249℃ / 0.6kPa / 배기 20)
- 1차 끝 직후 **스윙바이 확인** → 이후 RoR이 다시 오르기 시작하면
  - 즉시 대응: 드럼 추가 감속(21) 또는 가스 감압 (단, 이미 늦은 대응)
  - 다음 배치: **초중반 열을 줄이는 쪽**으로 수정 (이 글 핵심)
- 2차 팝 시점 RoR 방향을 매 다크 배치 품질 지표로 기록

## 프로그램 규칙 (TAAS 연동용)
```
[다크 로스팅 진단 — 1차 이후 RoR 추적]
- 1차 종료 이후 RoR 국소 최저점 = swing_by_point 감지
- swing_by_point 이후 30~60초 RoR 기울기:
  · 음(하강) → "정상: 열 운용 양호"
  · 0 또는 양(유지·상승) → 경고 "스윙바이 후 재상승: 열 축적/플릭 위험"
- 2차 팝 마킹 시점 RoR 기울기 >= 0 → 품질 플래그 "과열 구조 (조직 손상·과탄화·쓴맛 위험)"

[다음 배치 처방 — 원인은 이전 구간]
- 위 플래그 발생 시 2차 직전 조정 제안 대신:
  1) 초반~중반 가스 최대치 유지 시간 단축 또는 감압 시작 앞당기기
  2) 마이야르~1차 구간 배기 단계 상승 확인 (26·27 Aero Accel)
  3) 드럼: 1차 종료 신호에 추가 감속 (21 Gear Shift)
  4) 투입량·투입온도(축열) 점검 (11 다크 세팅)

[컵 연결]
- 다크 컵 태그: 텁텁함·스모키·불쾌한 쓴맛·평면적·거친 맛 → "2차 시점 RoR 상승" 구조 우선 의심
```
