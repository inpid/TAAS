## 1. 딘의 지역별 경험 정리
| 시기 | 장소 | 물 | 딘의 체감 |
|---|---|---|---|
| 전 직장 | 한림 저지리 | 한림·금악권 (한림정수장은 2025년 막여과로 경도 3~4) | "서쪽 물은 약하다, 수율 낮고 클린컵 좋음"의 출처 ✅ |
| 약 3년 전 카페 운영 | 애월 상가리 531-1 | 건물주 말: 어승생정수장 물 | TDS 측정 120ppm, "물이 굉장히 셌다"는 기억. 산미가 안 올라오고 맛이 뭉개짐, 대신 수율이 매우 좋음(드립 16~20g → 12~14g로도 맛이 잘 나옴). 처음엔 물 탓인 줄 모르고 로스팅만 탓함 → **브리타 수소(이온교환) 필터 "250" 계열을 끼웠더니 산미가 정상으로 나옴** |
| 현재 매장 | 중문권 | 회수정수장 (경도 52~54, TDS 134~140, pH 7.8~8.5) | — |

## 2. 상가리 물 분석
### 현장 조건 (딘 확인)
- 건물 지을 때 저류조(저수조)는 없었던 것으로 앎 → 저수조 오염·정체 가능성은 낮음
- 급수원 정보는 건물주의 "어승생에서 물이 온다"는 말뿐
- 건물주가 약 1만 평 부지를 통째로 사용 (상가 주소는 작아도 앞뒤 전부 건물주 땅)

### 데이터와의 대조
- ❗ 어승생정수장은 데이터상 **제주에서 가장 약한 물 중 하나**: 경도 15~35, 증발잔류물 49~80, pH 7.3~7.6 [W1] → "어승생 물이라 세다"는 데이터와 맞지 않음
- 상가리에는 **상가마을 마을상수도**가 따로 있음: 2026년 3분기 경도 36, 증발잔류물 92, pH 8.2, 염소이온 11.0 [W3]
- 애월정수장(애월읍 급수): 경도 31~36, 증발잔류물 81~86, pH 7.8~8.2
- 가능성 ⚠️
  1. 마을상수도(상가마을) 물
  2. 1만 평 규모 부지라 **자체 지하수 관정(사설 지하수)**을 썼을 가능성 — 사설 지하수는 공공 정수장보다 미네랄·중탄산이 높을 수 있음
  3. 3년 전 값이라 지금 데이터와 달랐을 수도 있음

### 왜 "수율은 좋은데 산미가 죽고 뭉개졌나"
- 결론: **경도(Ca·Mg)보다 알칼리도(중탄산·탄산경도)가 높은 물**이었을 가능성이 가장 큼
  - 120ppm 중 상당 부분이 중탄산·나트륨·실리카일 가능성 (제주 화산암 지하수는 중탄산·실리카 비중이 높은 편 ⚠️)
  - 중탄산이 커피의 유기산을 중화 → 산미 소실, 윤곽이 흐려져 "뭉개짐"
  - 적은 도징으로도 진하게 느껴진 건 용존 성분의 무게감 + 산미가 눌려 쓴맛·바디가 앞에 나온 영향 (실제 수율 상승 여부는 굴절계 없이 확정 불가)
- ✅ **브리타 수소 필터로 산미가 회복된 것이 이 결론을 강하게 뒷받침**
  - 브리타 Purity **Quell ST** 계열은 커피 업계용으로 개발된 필터로, **탄산경도(=알칼리도의 주성분)를 낮춰** 스케일을 막고, 염소·탁도·일부 중금속도 제거한다고 제조사·판매처가 설명 [웹: jurang.co.uk Brita Purity C500 Quell ST 제품 설명]
  - 원리: 수소이온(H⁺)형 이온교환 → Ca·Mg를 H⁺로 교환 → H⁺가 중탄산과 반응해 CO₂로 빠짐 → 알칼리도↓ → 산 중화가 줄어 산미 회복
  - 딘이 쓴 "250" 모델명은 정확히 확인 안 됨 (해외 판매 라인은 C50·C150·C300·C500·C1100 등). 국내 판매명이거나 구형 모델일 가능성 — 증상 개선 양상은 Quell ST(이온교환형)와 일치
- 교훈: **산미가 안 살면 로스팅보다 물의 알칼리도를 먼저 의심**

## 3. 매장 정수 필터 선택 (회수정수장 기준)
### 필수
- **세디먼트 + 활성탄(카본 블록)**: 잔류염소 0.5~0.6 mg/L 제거, 냄새·소독 부산물 제거

### 쓰지 말 것
- **RO(역삼투)**: 미네랄을 거의 다 걸러 한림 막여과수(경도 3~4)처럼 됨 → 쓰려면 리미네랄 장치와 세트로
- **나트륨 연수기**: Ca·Mg를 나트륨으로 바꿈 → 추출력↓, 맛 무거워짐. 경도 53이면 스케일 걱정도 적음

### 브리타 커피용 라인 구분 (판매처 설명 기준)
| 라인 | 방식 | 적합한 물 |
|---|---|---|
| Purity C **Fresh** | 특수 활성탄 혼합, 탁도·유기 불순물·맛 저해 물질 제거, 미네랄은 거의 안 건드림 | 판매처가 **연수 지역**용으로 권장 [웹: maxicoffee Purity C50 Fresh] |
| Purity C **Quell ST** | 이온교환으로 탄산경도(알칼리도)↓ + 바이패스 조절 | 알칼리도가 높아 산미가 눌리는 물 (상가리 사례) |
- 제조사는 설치 전 **물 경도를 먼저 테스트해서 모델을 고르라고** 권장 [웹: maxicoffee]

### 매장 물 KH(알칼리도)를 재보고 고르기
| KH 측정값 | 추천 |
|---|---|
| 약 40~50 이하 | Fresh(카본형)만으로 충분 |
| 약 60 이상 (pH 8 이상과 함께) | **Quell ST + 바이패스 넉넉히** → 상가리에서 효과 본 방식 |
- 회수 물은 pH 7.8~8.5로 높은 편 → 산미가 덜 사는 느낌이 있으면 Quell ST가 유력 후보
- 바이패스 주의: 제주 물은 이미 연수 경계라 전부 이온교환하면 추출력까지 깎임 → 원수 비율 높게
- 다른 브랜드: BWT(마그네슘 보충형 라인), 에버퓨어 — 국내 모델·가격 확인 필요
- 수업·커핑 기준수 고정용: 정제수(또는 RO수) + 커피용 미네랄 파우치·농축액

## 4. 로스팅 연결
- 물 때문에 생긴 맛 문제(산미 소실·뭉개짐)를 로스팅으로 고치려 하면 원두가 왜곡됨 → **커핑은 항상 같은 기준수로**
- 재생 프로그램 규칙 후보
  - 컵 평가에 물 정보(정수장·지하수 여부·TDS·KH·필터 종류) 필수 입력
  - "산미 소실 + 맛 뭉개짐 + 높은 TDS/pH" → 로스팅보다 **물 알칼리도 원인 우선** 플래그, Quell ST류 제안
  - "수율 낮음 + 클린컵 좋음 + 낮은 TDS" → 연수 플래그 (한림권 패턴), Fresh(카본형)·미네랄 보충 제안

## 검증 대기
1. 상가리 531-1 실제 급수원 (마을상수도 / 자체 지하수 관정 / 정수장)
2. 브리타 "250" 정확한 모델명 (국내 판매명 확인)
3. 제주 지하수의 중탄산·실리카·나트륨 비중 자료 (삼다수 성분표 포함)
4. 매장 물 KH 실측값
5. 브리타·BWT·에버퓨어 국내 판매 모델·가격
