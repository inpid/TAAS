## 1. 로스팅의 정의와 목표
- 생두 성분을 열로 분해·합성·증발시켜 맛과 향을 만드는 작업 [P][180] ✅
- 향미는 분해·합성·증발의 결과물 → 컵의 플레이버·맛·질감을 분석해 로스팅 과정을 **역추적**할 수 있다 [P] ✅
- 목표: 생두가 데미지를 입지 않는 선에서 최대한의 열량을 준다 [180]
- 주요 성분: 클로로겐산(→퀸산·카페익산), 자당(→포도당·과당) [P] / 클로로겐산=쓴맛·착색, 트리고넬린=향(로스팅 중 50~80% 분해, 피리딘·피롤 등 생성) [G] ✅

## 2. 프로파일의 의미
- 프로파일은 '기록'이 아니라 '설계'(투입량·시작온도·배출온도를 미리 정하고 실행). WRC도 설계 프로파일 [G]
- 프로파일은 항상 만들어서 사용, 크롭스터로 모든 배치 기록 [180]
- 설계 순서: **배출 온도 먼저 → 투입 온도**. 투입 온도↑이면 배출 온도도↑, 대신 화력은↓ [180] ⚠️
- 기준점: 옐로(색 변화 시점) · 1차 크랙 · 2차 크랙 · DTR. 이 기준으로 잡으면 어떤 머신에도 적용 가능 [G]
- 샘플 로스팅 기준은 예전 시간·온도 → 현재 DTR [G]

## 3. 단계별 화학 반응 [P]
| 단계 | 주요 반응 | 결과 | 비례 |
|---|---|---|---|
| 옐로 / 마이야르 | 건조되며 당+아미노산 반응, 고분자 분해, 탈수, 유기산 분해 | 갈색 색소, 굽지 않은 느낌의 플레이버 | 열량 강도+시간 |
| 브라운 / 캐러멜화 | 당이 고열에 반응, 탈수, 유기산 분해 | 갈색 색소, 쓴맛, 구운 느낌 플레이버 | 열량 강도+시간 |
| 크랙 이후 / 열분해 | 급격한 수증기 배출, 밀도 급변, 유기산 분해 | 검은 색소, 쓴맛, 초콜릿 플레이버 | 시간 (탄화는 강도+시간) |
- 디벨롭먼트: 1차 크랙 전후 발열반응 시작, 드럼 내 생두끼리 복사열 주고받음. 향·산미·단맛이 크게 변하거나 소멸, 탈수 진행되며 스파이스·마른 뉘앙스 [P]
- 로스팅 초반: 열이 표면→내부로 이동, 표면부터 수분 증발. 강한 열일수록 내부 미가열 영역이 작아짐 [P]
- 수분 증발 시작 약 55℃, 단백질 분해 약 177℃ [180] ⚠️ (단일 출처, 일반 문헌과 대조 필요)

## 4. 열 전달 3종
| 열 | 정의 | 커지는 조건 | 비유 [P] |
|---|---|---|---|
| 전도열 | 물체를 타고 이동 | 공기가열 효율 낮은 구조, 낮은 드럼 스피드, 생두를 덜 띄우는 교반, 앞뒤로 긴 드럼, 보온 낮은 하우징 [P] | 프라이팬: 닿는 정도 따라 편차, 표면 캐러멜화↑ |
| 대류열 | 유체가 움직이며 전달 | 빠른 대류·높은 공기가열 효율, 높은 드럼 스피드, 생두를 많이 띄움, 위아래로 높은 드럼, 보온 높은 하우징, 드럼 대비 적은 용량 [P] | 오븐: 고르게 익음, 표면 캐러멜화↓ |
| 복사열 | 매질 없이 파장으로 이동 | 두꺼운 드럼, 많은 투입량, 세라믹·할로겐 열원 [P] | 세라믹 솥: 적은 열로 내부까지 |
- 조절 요소(기센): 대류=배기(Pa)·가스·드럼 스피드(Hz) / 복사=예열 정도·투입 온도·가스 [180]
- 로스터기는 3가지 중 최소 2가지를 사용 [G]
- ❗ 비중: [180]은 "대류 > 복사 > 전도"(기센 기준)라 했고, 본인 메모로 "전도열 부분은 책과 많이 다름 → 다시 공부". [P]는 비중 순위 없이 머신 구조·조건에 따라 달라진다고 설명 → **머신별로 다르다고 보는 것이 안전**

## 5. 생두 변수와 대응
### 밀도 [P] ✅
- 정의: 일정 부피 용기에 담긴 생두 무게(g/L)
- 밀도↑ = 가열할 성분 많음 + 열의 내부 이동 방해 → 필요한 열량↑. 크랙 구간에서 세포벽이 충분히 부풀려면 충분한 열량 필요(조직이 질긴 생두도 유사)
### 경도 [180]
- ❗ 경도 ≠ 밀도 (예: 철은 구리보다 경도↑ 밀도↓). [P]는 "단단함/무름" 표현을 밀도와 함께 씀 → 용어 구분해서 저장
- 산지별 경도: 높음 콜롬비아·과테말라 / 중간 코스타리카·케냐·엘살바도르 / 낮음 에티오피아·브라질 ⚠️ (일반화, 생두마다 다름)
- 간이 측정: 로스팅 1분 넘어 샘플봉으로 몇 알 빼서 손으로 찢기 → 찢어지면 경도 낮음, 4분쯤에야 찢어지면 경도 높음
### 크기 [P]
- 작을수록 무게당 표면적↑, 중심까지 거리↓ → 열효율↑. 클수록 반대
### 대응표 (두 출처 방향 일치 ✅)
| 생두 | 투입온도 | 램프업/화력 | 배기 | 드럼 |
|---|---|---|---|---|
| 크고 단단 [P] / 경도↑ [180] | 낮게 | 빠르게·강하게 | 크게 [180] | 빠르게 [180] |
| 크고 무름 [P] / 경도↓ [180] | 높게 | 늦게·약하게 | 작게 [180] | 느리게 [180] |
| 작고 단단 [P] | 조금 낮게 | 조금 빠르게·조금 강하게 | | |
| 작고 무름 [P] | 조금 높게 | 조금 늦게·조금 약하게 | | |

### 수분
- 생두 수분 보통 9~11% [180], 건조 목표 10%대 [G] ✅
- 역할: 열을 내부로 전달하는 매개 + 급격한 열로부터 보호 [180] / 비열이 높아 수분 많으면 필요 열량↑, 열 이동을 방해하면서 동시에 전도체 [P] ✅
- 수분 높음: 표면만 먼저 마르면 내외부 편차 → 심하면 내부 언더+외부 오버 동시 발생. 중심 수분 데워질 시간·열량 확보, **탈색 시점(ROR 최대)에 ROR 높게 유지하되 속도는 과하지 않게**, 초반 램프업을 여러 단계로 나눠 마이야르~캐러멜~크랙~디벨롭 간격이 짧아지지 않게 [P]
- 수분 낮음: 초반 구간 짧게 [P]
- 결점 표현 [P]:
  - 언더디벨롭(건조 부족): 날카로운 신맛, 쪄진 느낌, 풋내, 설익은 향, 떫은 감
  - 베이크드(과건조): 마른 식물 향, 텁텁한 촉감, 밋밋하고 약한 신맛·플레이버

## 6. 머신 운용 (기센 기준) [180]
- 화력 감소 폭: 초반 1~2%씩, 후반 5~7%씩
- RoR이 심하게 흔들리면 배기(Pa)를 줄여 재로스팅
- 라이트 vs 다크 (배기 110Pa 기준):
  | | 라이트 | 다크 |
  |---|---|---|
  | 대류열 | 크게 | 작게 |
  | 온도 | 낮게 | 높게 |
  | 화력 | 크게 | 작게 |
  | 배기 | 110Pa↑ | 110Pa↓ |
  | 드럼 | 빠르게 | 느리게 |
  | 투입량 | 많이 | 적게 |
  ⚠️ "라이트=낮은 온도+큰 화력"은 노트 표현 그대로. 의미(투입온도인지 배출온도인지) 재확인 필요
- 투입량 범위 2~6kg (기센)
- 예열: 배기 최저 → 목표 에어온도 설정(예 230℃) → 1시간에 목표 도달하는 화력을 찾아 **항상 같은 화력으로 예열**
- 최대 화력 찾기 = 예열 테스트: 배기 최저(80Pa), 50/60/70% 각각 1시간 → W1은 55%가 적정(드럼은 작은데 가스판은 W6와 동일). 다음 로스팅에서도 검증
- 기센은 쿨링과 배기가 연결 → 쿨링 시 배기 최대(~170Pa)로 올리면 드럼도 식어 연속 배치 결과가 달라짐

## 7. 풍량·DTR [G]
- 어느 머신이든 로스팅 행위는 같다 → 화력·풍량·1차 크랙 이후 DTR 설계가 핵심
- 풍량↑ → 속이 잘 익음(스모키·베이크와 연관), 풍량으로 향 조절 가능
- 후반 풍량↓ → 향은 살지만 클린컵↓
- 화력보다 풍량 밸런스를 맞추는 게 더 좋다
- 커핑 웻 아로마에서 어두운 과일(자두·블루베리) 또는 그을린 향 → 에어플로 조절로 잡을 수 있음
- 이카와는 온도보다 DTR 중심으로 하면 재현성↑. 과제: 이카와 결과를 기센에 옮기는 법
- 사례: 파나마 게샤 워시드 — 엘리다(균일) DTR 약 17% / 루이또(등급 혼입, 불균일) DTR 약 20~23%. 게샤라고 무조건 약배전 아님

## 8. 샘플 로스팅·커핑 [G]
- 같은 생두를 색은 비슷하게 맞춰 3버전 비교:
  - 베이크드(저온 장시간, 약 20분): 플레이버 단조, 플랫, 언더 가능
  - 패스트(고온 단시간): 향↑ 맛 자극적. **패스트 ≠ 덜 볶은 것**
  - 일반: 기준점
- 커핑 질문: 괜찮은가? 바꿔도 되나? 어떻게? 이 생두의 힘을 최대로 끌어냈나? 잘 팔릴까?
- 맛의 기준이 정확해야 방향을 잡는다
- 매일 아침 원두 QC 후 추출 세팅. 로스팅 다음 날 커핑해도 무방

## 9. 생두 프로세싱·보관 [G]
- 수확: 피킹(균일) / 스트리핑 / 메커니컬(커머셜). 더블 피킹은 더 균일·고가. 옐로 품종은 숙도 판단 어려움
- 가공: 내추럴 / 펄프드(브라질 스페셜티 약 90%) / 세미워시드(클린컵↑ 바디↓) / 더블패스(펄핑 전 물탱크 하루 숙성 → 과일향↑) / 허니(코스타리카, 물 절약 목적, 화이트~블랙) / 워시드(트래디셔널·풀리·케냐·수마트라(실버스킨까지 제거, 클린컵↑ 외관↓)·에티오피아)
- 발효: 뮤실리지=당·펙틴·지방족산. 정상 워시드 pH 4.8~5.1, 4.8 미만이면 과발효(사워). 물 1kg당 15~20L. 탱크는 세척 후 재사용
- ⚠️ "커피 가공에서 삼투압은 일어나지 않는다"는 강사 주장 — 논쟁 여지 있음, 추가 자료로 확인 필요
- 건조: 선드라이(날씨 의존) / 메커니컬(60~70℃ 온수 통로) / 찬바람 건조
- 선별: 메커니컬·일렉트로닉(낱알 인식, 곰팡이·벌레 먹은 것 제거). 좋은 선별기 = 해마다 균일한 품질
- 보관: 18℃ / 습도 60%. 습도 1%↑마다 생두 수분 약 0.18%↑ ⚠️ (단일 출처)
- 디카페인: 표면이 벗겨진 상태라 오염·산화 빠름, 로스팅 방법은 동일
- 로스트 로스(%) = (생두 무게 − 원두 무게) ÷ 생두 무게 × 100
- 산지 메모: 부룬디·온두라스·콜롬비아는 국내 도착 후 맛 저하 크다는 의견. 콜롬비아는 로스트·너츠·초콜릿 베이스로 활용 제안 ⚠️ (강사 의견)

## 10. 머신 분류 [G]
- 배치형 / 연속형 · 가스 / 전기(이카와·스트롱홀드) / 기름
- 드럼(기센·프로밧·디드릭·후지로얄) / 보울 / 스월링(이카와) / 고정드럼(스트롱홀드) / 유동층(로링)
- 냉각: 수냉(간접) / 공냉

## 재생 프로그램용 규칙 후보 (if-then)
- 생두 밀도·경도↑ → 투입온도↓, 초반 화력↑, 배기↑, 드럼↑
- 수분↑ → 초반 구간 길게, 램프업 분할, 탈색 시점 ROR 유지
- 수분↓ → 초반 구간 짧게
- RoR 불안정 → 배기↓
- 컵: 날카로운 신맛·풋내·쪄진 느낌 → 언더(건조 부족) 의심
- 컵: 마른 식물·텁텁·밋밋 → 베이크드 의심
- 컵: 웻 아로마 그을림/어두운 과일 → 풍량 조절
- 후반 풍량↓ → 향↑ 클린컵↓ (트레이드오프)
- 원두 불균일(등급 혼입) → DTR 길게 (게샤 사례 17% → 20~23%)

5. 습도 1% → 생두 수분 0.18%
