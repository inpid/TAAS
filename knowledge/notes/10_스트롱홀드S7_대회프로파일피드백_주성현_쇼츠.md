# 대회 예선 연습 프로파일 피드백 — 주성현 (Stronghold S7) + 드럼 로스터 해석

- 출처 [YT7]: https://youtube.com/shorts/iQi1pFyfalg (2:54)
- 화자: 주성현 — 로스팅 챔피언, 180커피로스터스 본부장 (01 노트 [180] 수업 강사와 동일 인물)
- 내용: 로스팅 대회 예선을 앞두고 팀원 3명(동형·이상호·차민석)의 연습 프로파일 비교 피드백
- 머신: **Stronghold S7** / 생두: 브라질 / 투입량 0.5kg (화면 판독)
- 판독 방법: Claude가 크롬에서 영상 프레임을 1초 간격으로 넘기며 화면 자막을 읽음. 자막 일부 누락·오독 가능 🔍

신뢰도: ✅ 기존 노트와 일치 · ⚠️ 이 영상 단독 · ❗ 기존 노트와 충돌 · 🔍 판독 불확실

## 스트롱홀드 용어 (06 노트 매핑 보강)
| 스트롱홀드 | 열 종류 | 드럼 로스터 대응 |
|---|---|---|
| 열풍 | 대류 | 버너 화력이 만드는 뜨거운 공기 + 배기(풍량) |
| 할로겐 | 복사 | 드럼 벽·하우징이 내뿜는 복사열(축열), 일부 버너 화력 |
| 드럼히터 | 전도 | 드럼 표면 온도(예열·투입온도·드럼 축열) |
| 교반 | 콩의 움직임 | 드럼 스피드(기센 Hz, 이지스터 회전수) |
- 화면 온도 표기: "내부"(드럼 내부 공기 ≈ ET)와 "원두 표면"(≈ BT) 🔍

## 1. 1위 프로파일 — 동형 (예선 1등)
| 항목 | 값 |
|---|---|
| 투입온도 | 200℃ |
| 시작 세팅 | 열풍 9 / 할로겐 4.5 / 드럼히터 4.5 / 교반 1 |
| 터닝포인트 | 01:10 (내부 132.4℃ / 원두 표면 120℃) 🔍 |
| 1차 크랙 | 06:26 (내부 177℃ / 원두 표면 206.8℃) 🔍 |
| 배출 | 07:10 (내부 182℃ / 원두 표면 212℃) 🔍 |
| DT / DTR | 0:44 / 10.2% |
- 운용
  - **초반부터 충분한 열량을 쭉 공급**
  - 조절해야 하는 시점부터는 **모든 열원(열풍·할로겐·드럼히터)을 동시에 줄여가는 형태**
  - **교반을 최대한 낮춰서** 대류 등을 제어하며 진행

## 2. 이상호 프로파일
- 진행·조절 방식은 동형과 거의 비슷
- 차이: **투입온도 약 10℃ 낮게, 열풍 0.5 정도 강하게**, 나머지 동일
- 결과: 투입온도가 낮아 **총 로스팅 시간 약 30초 길어짐**, 1차 팝 이후 빼는 것은 오히려 짧았음
- 평가: 길어지면서 동형보다 **맛의 인텐스(강도)가 줄어 점수가 낮게 나왔을 것**으로 봄

## 3. 차민석 프로파일 (본인이 가장 자신 있던 것)
| 항목 | 값 |
|---|---|
| 투입온도 | 200℃ |
| 시작 세팅 | 열풍 9 / 할로겐 4 / 드럼히터 6 |
- 두 사람과 완전히 다른 형태
  - **교반을 하나 올려** 대류(위쪽 공기)로 열을 더 공급하려는 목표로 진행 🔍
  - 드럼히터는 특정 지점까지 열을 주고 그 뒤 거의 완전히 줄여 **드럼이 식어가면서 열을 전달**하는 방식
  - 열풍만 계속 줄여오다가, **1차 팝 무렵 할로겐을 급격하게 거의 꺼버림**
- 평가
  - **할로겐(복사열)을 후반까지 끌고 온 것이 쓴맛(비터)의 원인**이었을 것 — 스코어시트에서 비터가 지적됨
  - 동형·상호처럼 **열을 같이 줄여왔으면** 좋았을 것
  - **너무 짧은 시간에 열을 많이 빼다 보니** 로스팅이 좀 더 길어진 것 같음
- 마무리: 1등 프로파일을 잘 보고 연구해서 다음 대회 성적을 올리자

## 4. 핵심 원칙 정리
1. **초반에 충분한 열량** (✅ 11 노트 주성현 이지스터 강의, 01 Prequel·180, 06 임지영 "초반이 가장 열을 많이 넣을 수 있는 구간")
2. 줄일 땐 **모든 열원을 함께, 단계적으로** — 한 열원만 늦게까지 남기거나, 막판에 한꺼번에 끊지 말 것
3. **후반 복사열(할로겐) 잔존 → 쓴맛** ⚠️
4. 투입온도 10℃ 차이만으로도 시간 +30초 → 인텐스↓ (같은 생두·같은 조작에서) ⚠️
5. 급격한 열 감소 → 진행 지연(늘어짐)

## 5. 드럼 로스터(이지스터·기센)로 해석하기 ⚠️ Claude 해석
| 스트롱홀드에서 한 일 | 드럼 로스터로 옮기면 |
|---|---|
| 초반 열풍·할로겐·드럼히터 모두 높게 | 충분히 예열된 드럼 + 초반 높은 화력. 투입~터닝~약 140~150℃까지 열을 최대로 (11 노트와 같은 원리) |
| 조절 시점부터 모든 열원 동시 감소 | 드럼은 열원이 사실상 버너 하나 → **가스를 단계적으로 줄이면서 배기(풍량)를 같이 맞춰** 대류·복사의 균형을 유지. 가스만 확 줄이고 배기는 그대로 두거나, 배기만 바꾸는 식의 한쪽 조작은 피함 |
| 교반 최소 | 드럼 스피드를 기종의 정상 범위 안에서 낮은 쪽으로 → 전도·복사 비중↑, 대류↓. 단 대용량(20kg 등)에서 너무 낮추면 스코칭 (❗ 02 이지스터 코칭) → 소용량 샘플 로스터에서나 유효한 선택 |
| 할로겐을 늦게까지 유지 → 쓴맛 | 드럼 벽에 쌓인 축열이 후반까지 남는 상황과 같음 → **초반 과도한 고화력·과예열로 드럼이 뜨겁게 달궈진 채 1차를 맞으면 쓴맛** (✅ 02 "드럼은 가스를 줄여도 바로 안 식는다") → 1차 전 미리 가스를 줄여 축열을 빼 둠 |
| 1차 직전 할로겐 급차단 → 늘어짐 | 1차 직전 가스를 한 번에 크게 끊으면 RoR 급락·크래시·늘어짐 (✅ 05 케냐 "크래시 = 베이크드 위험") → 크게 끊지 말고 미리 나눠서 |
| 투입 10℃ 낮음 → +30초, 인텐스↓ | 드럼에서도 투입온도↓ = 총 시간↑. 내추럴·소프트한 생두(브라질)는 길어지면 맛이 흐려짐 (❗ 05 케냐 하드 워시드는 투입↓로 오히려 좋아짐 → **생두 경도·가공에 따라 방향이 반대**) |
| DT 44초, DTR 10.2% (약 7분 배치) | 짧은 디벨롭으로 향·인텐스 유지 (✅ 03 ETeRR 0:51, 04 레벨 2 패턴) |

## 재생 프로그램 규칙 후보
- 열원 감소 시 "단일 열원만 남김" 패턴 감지 → 후반 쓴맛 경고 (스트롱홀드: 할로겐 / 드럼: 높은 드럼 축열 + 늦은 가스 감소)
- 1차 직전 화력 변화량 > 임계값 → "급차단: 늘어짐·크래시" 경고
- 같은 생두에서 투입온도 −10℃ → 총 시간 약 +30초 (S7, 0.5kg 브라질 기준) 참고값
- 머신 매핑 표에 스트롱홀드 3열원(열풍/할로겐/드럼히터) + 교반 추가
