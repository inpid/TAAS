# 배치 간의 간격 설정 — BBP 온도 찾는 법 (주성현)

- 출처 [BL25]: 네이버 블로그 "로스팅패스파인더"(주성현) 2024-08-27. 딘 제공 캡처 1장
- **딘 시운전 때 바로 쓸 절차** → 00 노트 시운전 순서 2번(예열·BBP 고정)에 연결

신뢰도: ✅ 기존 노트와 일치

---

## 1. 왜 필요한가
- 배치 간 간격을 정확히 관리하지 않으면 결과물의 일관성을 유지하기 어려움
- BBP(Between Batch Protocol)는 **로스터 기계마다 다르게** 설정하는 것이 좋음
- 가장 중요한 건 **드럼이 일정한 열을 유지하도록 준비**하는 것
- 매일 적게는 10배치, 많게는 30배치 — 같은 커피를 여러 번 볶을 때 동일한 진행 방식으로 이어가는 핵심이 BBP
- **예열도 BBP에 포함**: 드럼이 고르게 열을 품도록 준비하는 과정. 이때 **작은 화력과 느린(낮은) 배기**가 유리
- ✅ 01 [180] "예열: 배기 최저, 항상 같은 화력", 12 라오 "BBP는 라오가 만든 용어", 03 ETeRR "180℃ 리셋"

## 2. BBP 온도 찾는 절차
1. **같은 배치 크기**의 커피를 몇 배치 준비
2. 로스터를 **충분히 예열**한 후 **첫 배치** 진행
3. 배치가 끝나면 **배기 속도를 느리게** 조정하고 **불을 끔**
4. **투입온도보다 10℃ 낮은 온도까지 쿨다운** → 다시 (가열해) 로스팅을 동일하게 진행
5. 이때 로스팅 시간이 **현저히 짧아진다면** → 다음 배치는 **투입온도보다 20℃ 낮은 온도까지 쿨다운** 후 다시 예열해 진행
6. 이렇게 반복하며 **로스팅 시간이 일정해지는 쿨다운 지점**을 찾으면 → 그 온도가 사용 중인 로스터의 **'배치 간 간격 온도'**
- 찾아낸 쿨다운 온도로 BBP를 설정하면 매 배치 일관성 확보에 큰 도움

```
[BBP 기록 (배치마다 자동)]
- drop_time, BBP 시작 시 BT/ET, 불 끈 시점, 최저 온도(쿨다운 도달값), 재가열 시작~투입까지 시간, 투입 시 BT/ET

[BBP 탐색 모드]
- 사용자가 "BBP 테스트" 시작 → 쿨다운 목표 = charge − 10℃ 제시
- 다음 배치 총 시간이 이전보다 기준(예: 20초) 이상 짧음 → 쿨다운 목표 −10℃ 더 낮춤 제안
- 연속 2배치 TP·총 시간 차가 기준 안 → "BBP 온도 확정: charge − X℃" 저장 (머신 프로필)

[운영]
- 확정 후: 배치 종료 시 "배기↓·불 끔 → X℃까지 쿨다운 → 재가열" 단계 안내
- 쿨다운 도달값이 확정값에서 ±3℃ 벗어나면 경고 "BBP 불일치: 배치 비교 신뢰도↓"
```
