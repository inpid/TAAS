# 다음 단계 — 딘 이지스터 1.8 기준 데이터 수집 (2026-10-25 갱신)

## 현재 상태
- 학습 노트 01~50 완료 (이론·이지스터·기센·스트롱홀드·이카와·제주 물·라오·WCRC·국내 출처·통합 노트·주성현 블로그 다수)
- 출발점 레시피는 가능 (17 통합노트 + 23·47·49·50 이지스터 1.8 실전 세팅), 딘 머신 보정 레시피는 기준 데이터가 필요
- 딘 계획: 로스터기 설치 후 TAAS 프로그램으로 직접 연결해 데이터 쌓기

## 딘 확인 사항 (해소)
- ETeRR = Environmental Temperature Response Roasting. 180커피 교육 정의와 동일
- 딘은 2020년 3월 180 수업 수강, 직전에 프릳츠커피 커핑 8회차 수료
- 딘 이지스터 1.8은 **로스팅 중 드럼 RPM 가변 모델**, 아직 시운전 전
- Aero Accel은 딘 수업 당시 없었음. 2025년 단톡방에서 듣고 큰 기계로 해봄 (블로그상 Aero Accel은 2024년 중반 이전부터 운용, 46 노트)
- 로스팅패스파인더 블로그 운영자 = 180커피 주성현 (23 노트)
- **이지스터 1.8 운용 범위 500g~2kg** (49 노트, 주성현)
- **화력 단위 = mmAq**, **배기 = 댐퍼 10 개방 + 팬 스피드 다이얼** (50 노트)
- 이지스터 1.8 1차 온도대(주성현 프로브): 약 200~204℃

## 시운전·기준 배치 순서 (변수 하나씩)
1. 시운전·시즈닝, 프로브(굵기·위치)·TAAS 연결 확인, **드럼 RPM 1분간 실측**
2. **BBP 테스트** (45 노트 시트): 투입 −10℃ 쿨다운부터
3. **기준 배치 A**: 1kg, 고정 RPM(75), 배기 15→TP 35~45 → 딘 머신 TP·옐로·1차 온도대 확보
4. Aero Accel 단계 추가 (37 트리거: TP / 140~150℃ / 1차 근처)
5. Gear Shift만 추가 (21)
6. 배치 크기 확장 테스트: 1.2 → 1.5 → 2kg (49 표 참고), 500g 소량 테스트 (36)
7. 컵(단맛·클린컵·애프터·비터·결점)으로 A/B 판정

## 배치마다 남길 것
- 생두: 이름·산지·품종·가공·밀도·수분·스크린·소프트 포인트(온도·시간)
- 환경: 실내 온습도·외기 온도·생두 수분 (32·44)
- 세팅: 투입량·BBP(쿨다운 최저·재가열)·투입온도·화력(mmAq)·배기(팬)·드럼 RPM
- 이벤트: TP·ET TP·옐로(색)·1차(소리+RoR 꺾임)·배출 (시간+온도)·DT·DTR
- 조작: 화력/배기/RPM 변경 시점과 값
- 결과: 손실률·홀빈/분쇄 컬러·밀도
- 컵: 커핑 노트 + 사용한 물(회수정수장·필터·TDS·KH)

## 같이 확인할 것 (남음)
- 매장 물 KH 실측 → 필터 결정 (09)
- 11 노트 강의 표기 "0.6~0.8kPa"와 딘 화면 mmAq 표기 대응
- 딘 매장 습도와 진행 속도 상관 (32 vs 44 판정)
- 01~50의 "프로그램 규칙"을 TAAS용 규칙 사양서로 통합 (딘 요청 시)
