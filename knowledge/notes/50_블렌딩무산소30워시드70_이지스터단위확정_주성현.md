# 블렌딩: 무산소 30% + 워시드 70% — 그리고 이지스터 1.8 단위 확정 (주성현)

- 출처 [BL30]: 네이버 블로그 "로스팅패스파인더"(주성현) 글 (제목·날짜 캡처에 없음). 딘 제공 캡처 2장
- **중요: 이지스터 1.8 화력 단위와 배기 조절 방식이 이 글로 확정됨** (00·11·18·23·47·49 노트의 단위 질문 해소)

신뢰도: ✅ 기존 노트와 일치 · ⚠️ 글쓴이 단독 · 🔍 그래프 판독

---

## 1. 블렌드 구성과 목적
- **콜롬비아 무산소 30% + 과테말라 워시드 70%**
- 블렌딩에는 여러 목적이 있음
- 요즘 같은 "프로세싱 춘추전국시대"에 만들어지는 **무산소 발효 커피**는 맛과 향이 무척 **강렬**
- 이런 향은 **강도가 너무 강해 긍정적이기보다 오히려 부정적**으로 느껴지는 경우도 있음 → 사람이 긍정적으로 느끼는 **향의 강도·농도**가 있기 때문
- 그래서 향이 강한 커피를 **단맛·산미가 좋고 밸런스 좋은 커피**와 블렌딩하면, 향의 강도·농도가 약해지면서 **훨씬 더 좋은 결과**를 보여주는 경우가 많음
- ✅ 47 노트 "인퓨즈드는 산미 강도를 낮춰 향을 살림" (같은 문제의식: 강한 가공 향을 '적정 농도'로)
- ✅ 20 노트 블렌드 "각 20% 이상, 2~4종" (30/70 구성), 15 WCRC "주력 + 보조"
- 07 노트 "무산소·신가공은 큐 체계에 기준 없음, 이질 노트 주의"

## 2. 세팅 (이지스터 1.8, LPG)
| 항목 | 값 |
|---|---|
| BBP | **190℃까지 쿨다운** (배기 최저 / 화력 0) → **190℃부터 예열** (배기 15 / 화력 20) |
| 투입온도 | **200℃** |
| 화력 | **100mmAq** |
| 배기 | **15 → 45 (ET TP)** — **댐퍼는 10으로 개방, 팬 스피드 조절 다이얼로 조절** |
| 드럼 | **70rpm** |
| 투입량 | 미기재 🔍 |

### ✅ 단위·조작 방식 확정
- **화력 단위 = mmAq (가스압)**
  - 이 글: 시작 화력 **100mmAq**
  - → 23 노트 "가스 90 → 50", 47 "화력 84~88", 49 "화력 145", 18 "화력 95"도 모두 **mmAq**로 읽음
  - 예열·BBP의 "가스 18"(47), "화력 20"(이 글)도 mmAq → 23 노트 "예열 시 가스압 약 18mmAq"와 일치
  - ⚠️ 11 노트(주성현 강의 자막)의 "0.6~0.8kPa" 표기는 다른 기종·표기 단위로 보임 (1kPa ≈ 102mmAq). 딘 머신 화면 단위 시운전 때 최종 확인
- **배기 = 댐퍼 10(개방) 고정 + 팬 스피드 다이얼** → 11 노트 주성현 권장("댐퍼는 전체 개방, 팬 스피드로 배기 조절")이 **이지스터 1.8에서 가능**하다는 확인 (00 노트 "팬 스피드 옵션 여부" 해소)
- **배기 상승 트리거 = "ET TP"** → BT가 아니라 **ET의 터닝포인트**(ET가 바닥 찍고 반등하는 지점)에서 배기 변경 (21 노트 "ET 터닝포인트 부근 Shift Up"과 같은 기준)
