- 출처 [BL17]: 네이버 블로그 "로스팅패스파인더"(주성현) 글 일부 (제목·날짜 캡처에 없음). 딘 제공 캡처 1장
- 딘 메모: **외워두기**
- 그래프: 실제 로스팅 로그(이지스터, TP 95.2℃·1:14) 위에 개념 곡선 3개를 겹쳐 그림 🔍
  - 파랑 = **총 수분 증발** (약 3분대 정점 후 감소)
  - 초록 = **원래 생두 수분**으로 인한 증발 (약 2분대 정점)
  - 분홍 = **화학 반응으로 생긴 수분**의 증발 (약 4분대 정점, 완만)
  - 하단 로그 판독(🔍): 화력 81 [163℃, 5:26] → 79 → 74 → 70 → 66 → 62 → 58 → 54 → 50 → 46, 공기 40 [약 4:17] → 45 [192℃, 8:57], 1차 약 10:43(202℃), DT 0:35(5.1%), 배출 약 11:18(204℃)

## 암기 카드
### ① 로스팅 중 증발하는 물은 두 종류
1. 생두가 **원래 가지고 있던 수분**
2. **화학 반응(마이야르 등)으로 새로 만들어진 수분**
- 이 두 수분이 로스팅 전반에 걸쳐 **열을 전달하면서 증발** → ✅ 33 노트 "수분 = 열 전달 + 열 방어"

### ② Aero Accel = 로스팅 중 배기를 4~5회 단계 가속
| 시점 (트리거) | 배기 | 이유 |
|---|---|---|
| **투입** | **최저** | 아직 증발이 충분하지 않음 → 커피 표면 건조(드라이) 방지 |
| **터닝포인트** | 1차 가속 | 수분이 본격적으로 증발 시작 → 드럼 내부 수분율 조절, 더 나은 열전달 |
| **BT 140~150℃** (3mm 열전대 기준) | 2차 가속 | 원활한 열전달 |
| **1차 팝 부근 — BT RoR 하강률이 낮아지거나 정체될 때** | 3차 가속 | 과한 열이 공급되지 않도록 |
| (필요 시 추가) | | 총 4~5회 |
- = **수분 증발에 맞춰 배기 속도를 바꿔 열전달을 원활하게** 하는 방법
- ✅ 23 노트 실전: 15Pa(투입) → 35(TP) → 50(약 153℃) → 60(1차)
- ✅ 27·28 노트 원리: 초기 보호 → 중반 보강 → 후반 브레이크

### ③ 효과
- 플레이버·**클린컵**이 좋아지고 **단맛이 강해지는** 경향
- 이유: 배기 속도가 빨라지면 클린컵이 좋아지는 속성 + 적정한 열전달로 커피가 다치지 않고 온전하게 맛을 다 만들어냄

## 프로그램 규칙 (TAAS 연동용)
```
[Aero Accel 트리거 (이지스터, 3mm 프로브 기준)]
- 투입: exhaust = min
- TP 감지 → 제안 "배기 1단계 가속"
- BT 140~150℃ → 제안 "배기 2단계 가속"
- 1차 근접(예상 1차 60초 이내) AND BT RoR 하강률 감소 또는 정체(10~15초 지속, 21 노트) → 제안 "배기 3단계 가속"
- 한 배치 배기 가속 횟수 4~5회 초과 → 경고 "과조작"
- 프로브 굵기가 3mm가 아니면 → 140~150℃ 트리거 온도 보정 필요 표시
```
