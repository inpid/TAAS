# 색, 디벨롭먼트, 배출 전 온도 상승 그리고 스윙바이 (주성현)

- 출처 [BL22]: 네이버 블로그 "로스팅패스파인더"(주성현) 2024-09-05. 딘 제공 캡처 7장
- 다크 로스팅 예시 그래프(이지스터 추정 🔍): 가스(미압) 78 [189.7℃, 5:28] → 70 [196.9℃, 5:59] → (풍속 90 [199.5℃, 6:11]) → 1차 시작 **200.8℃, 6:17** → 64 [206.4℃, 6:52] → 58 → 52 → 46 → 40 [218.6℃, 8:08] → 34 → 26 [226.0℃, 8:45] → 2차 시작 **230.6℃, 9:07** → 13 [232.3℃, 9:16] → 배출 약 233℃ 🔍
  - BT RoR: 1차 이후 꺼졌다가 → 약 7분 반 저점 → **가스를 계속 줄이는데도 다시 상승(스윙바이)** → 배출

## 1. 커피의 색
- 로스팅 마지막 온도가 원두 외관을 결정. 하지만 **색만으로 맛을 완전히 판단·예측할 수 없음** (커피마다 같은 온도에서도 색이 다르게 표현됨)
- **라이트**: 낮은 배출 온도, 복합적인 향과 산미 보존. 단맛이 부족하다고 여겨지기도 하지만 그건 **로스팅의 문제**. 적절히 볶으면 매우 달고 풍부함
- **미디엄**: 다크와 라이트 사이, 많은 스페셜티 로스터가 에스프레소·필터에 사용. 충분한 단맛과 인텐스, 소비자에게 적절히 어필
- **다크**: 높은 배출 온도, 산미가 거의 없고 진한 단맛과 스모키 뉘앙스. 하지만 다크가 항상 바디감·단맛이 강한 건 아님 → **다크에 어울리는 생두를 선택**하는 게 중요 (✅ 11 "소프트 커피는 다크에 어울리지 않음")
- ✅ 20·34 노트 "같은 색도 ≠ 같은 로스팅"

## 2. 디벨롭먼트 — DTR에 매몰되면 안 되는 개념
- 디벨롭먼트 = 단순히 DTR이 아니라, **로스터가 원하는 포인트에서 커피가 정상적이고 이상적으로 만들어졌는가**
- DTR(1차 팝부터 종료까지 시간 ÷ 전체 시간)은 **재현성 확인·로스트 정도 예측**에 유용한 정도로 제한. 같은 커피·같은 조건의 일관성 확보엔 유용하지만 **품질의 절대 기준이 아님** — 열 관리·공기 흐름·온도 제어 등 다른 변수가 결과에 큰 영향
- 디벨롭의 목표: **원두 내부와 외부가 균일하게 발달**. 색과는 별개로 고려
| 상태 | 결과 |
|---|---|
| 디벨롭 **부족** | "**빈**" 맛, 추출 과정에서 **용해 가능성 낮음** → 추출 효율↓ → 산미·풍미가 빈약하거나 불쾌 |
| 디벨롭 **과도** | 복합적인 풍미 상실, **무미건조한 맛과 쓴맛**. 로스팅 시간이 지나치게 길어져 최적점을 넘길 때 발생 |
- 본질: 의도한 포인트에서 균일하게 발달 → **색상과 관계없이** 풍부하고 달콤
- ✅ 12 라오 "DTR은 QC 도구, 배출은 색·BT로", 24 노트 "DTR은 머신 규모별로 다름", 22 "겉색 vs 분쇄색 괴리"

## 3. 로스팅 종료 전 온도 상승
| 현상 | 정의 | 결과·원인 |
|---|---|---|
| **베이크드** | **1차 팝 직전과 팝 이후 속도(RoR)가 급격히 증가** | 단맛 부족, 애프터 얇음, 밋밋. 로스팅 중 온전한 열량 공급 실패, 또는 다른 요인의 과도한 열량 |
| **플랫라인(Flatlined)** | BT 상승이 **멈추거나 너무 오래 정체** | 디벨롭이 덜 되어 산미·단맛 빈약하고 얇음, 또는 불쾌한 산미·무미건조. 필요한 열을 충분히 못 주거나 **너무 빠른 배기**, **열량 조절을 너무 크게** 진행 (✅ 39 "큰 폭 화력 조절") |
| **이상적** | 1차 이후 온도(RoR)가 **점차 줄어들며 서서히 상승** | 베이크드·플랫라인 없이 균일한 발달 |
- ❗ 베이크드 정의: 이 글은 "1차 전후 RoR 급증", 12 라오는 "RoR **크래시** = 베이크드 / **플릭** = 로스티". 이 글의 플랫라인이 라오의 크래시·스톨에 해당 → 결과적으로 "**1차 전후 RoR이 매끄럽게 줄지 않고 튀거나 꺼지면 결점**"이라는 결론은 같음

## 4. 다크 로스팅의 스윙바이(Swing By)
- 종료 전 상승을 **요하는** 단계 = **다크 로스팅**
- **스윙바이**: 1차 팝 이후, **이전에 축적된 열을 이용**해 BT RoR이 가속되는 현상 → 다크에서 특히 유용
- 열의 **관성** 때문에 1차 이후 열을 적게 공급해도 BT가 자연스럽게 상승 → 원두가 과도한 열에 노출되지 않으면서 점진적으로 진행 → 다크에서 **태우거나 스코칭 없이** 복잡한 맛
- 그래프: 1차 이후 가스를 **64 → 13까지 계속 줄이는데도** RoR이 저점 후 다시 오름 = 관성에 의한 스윙바이
- 스윙바이가 **안 일어나고 BT RoR이 플랫라인**이면 → 디벨롭이 멈춰 **언더 또는 베이크드**, 목표 배출 지점까지 진행이 어려움
- 이를 피하려고 **1차 이후 과도하게 열을 가하면** → 이미 수분이 많이 빠진 상태라 **탄맛·재 맛** 위험
- → 다크의 핵심 기술 = **자연스러운 열 관성을 통한 온도 상승(스윙바이) 관리**: 1차 전까지 충분히 쌓고, 1차 후엔 줄이면서 관성으로 끌고 가기
- ✅ 11 주성현 "다크는 스윙바이를 잘 만들어서 낮은 열량을 공급하면서도 빈 온도는 충분히 상승", 40 "1차 흡열 플래시 후 발열 활성 = 스윙바이"

### ❗ 29 노트(2025-05, 같은 저자)와의 차이와 정리
- 29: 스윙바이 **이후 RoR이 다시 하강**해야 좋음(A), 스윙바이 후 **고점 유지·상승 → 과열**(B)
- 42(이 글, 2024-09): 다크에선 1차 후 관성에 의한 **RoR 가속(스윙바이)이 필요**
- 정리(Claude): **스윙바이 자체는 다크에 필요하다(42)**. 단 그 상승은 **가스를 단계적으로 계속 줄이는 상태에서의 관성 상승**이어야 하고, **2차를 향해 RoR이 계속 치솟거나 고점에 머무르면 과열(29 B)**. 즉 "스윙바이는 만들되, 키우지 않는다"
  - 이 글 그래프도 가스를 78 → 13까지 대폭 줄이며 관성만으로 끌고 감
  - 29의 B는 스윙바이 후에도 열 축적이 남아 RoR이 내려오지 않은 경우

## 딘 적용
- **라이트·미디엄**: 1차 이후 RoR은 "점차 줄며 서서히 상승" (플랫라인·급증 둘 다 피함)
- **다크**:
  1. 1차 전까지 충분한 열 축적 (11 다크 세팅: 투입 249℃ / 0.6kPa / 배기 20 / 800g)
  2. 1차 이후 가스를 단계적으로 크게 줄이며 **관성으로 스윙바이** 만들기
  3. 스윙바이 후 RoR이 2차를 향해 **계속 오르면** → 다음 배치 1차 전 열 축적을 줄임 (29)
  4. 스윙바이가 **안 오고 플랫라인**이면 → 1차 전 열 축적 부족 → 다음 배치 1차 전 열↑ (1차 후 열 추가로 해결하지 않기)
- DTR은 확인용, 판정은 컵·색(홀빈/분쇄)·손실률

## 프로그램 규칙 (TAAS 연동용)
```
[1차 이후 RoR 패턴 분류]
- flatline: 1차 후 BT RoR ≈ 0 (또는 BT 상승 정체) 지속 >= 30초 → "플랫라인: 디벨롭 정지, 언더/베이크드 위험"
  · 원인 후보: 1차 전 열 축적 부족, 배기 과다, 큰 폭 감압 (39)
- spike: 1차 직전~직후 BT RoR 급증 → "급가속: 베이크드/로스티 위험" (12·42)
- swing_by (다크): 1차 후 RoR 저점 → 재상승 감지
  · 재상승 중 가스 감소 진행 → "관성 스윙바이 (정상)"
  · 재상승이 2차 시점까지 계속 증가/고점 유지 → "과열 스윙바이" (29)
- ideal (라이트·미디엄): 1차 후 RoR 단조 감소 + BT 완만 상승

[다크 처방]
- flatline → 다음 배치 1차 전 열 축적↑ 제안 ("1차 후 가스↑"는 제안하지 않음: 탄맛·재맛)
- 과열 스윙바이 → 다음 배치 1차 전 감압 시작 앞당기기 + 1차 종료 시 드럼 감속(21)
```
