# TAAS 학습용 로스팅 지식 패키지

딘의 "로스팅 및 커피자료 프로젝트"에 저장된 노트 53개(00~52)를 그대로 뽑아 묶은 것. 2026-10-29 기준.

## 들어 있는 것
| 파일 | 용도 |
|---|---|
| `notes/00~52_*.md` | 원본 노트 53개 (프로젝트와 내용 동일) |
| `00_ALL_로스팅지식_합본.md` | 53개를 한 파일로 합친 것. AI에게 통째로 읽힐 때 |
| `01_TAAS_프로그램규칙_모음.md` | 노트 50개에서 "프로그램 규칙 / 레시피" 부분만 뽑은 것. 코드로 옮길 때 이 파일부터 |
| `index.json` | 노트 번호·제목·파일 경로·태그·규칙 유무 목록. 프로그램이 노트를 찾아 읽을 때 |

## 프로그램에 넣는 방법 (용도별)
1. **Claude Code로 TAAS 코드를 만들고 있다면**: 이 폴더를 프로젝트 안에 `knowledge/`로 넣고, `CLAUDE.md`에 "로스팅 판단은 knowledge/01_TAAS_프로그램규칙_모음.md 규칙을 따르고, 근거는 knowledge/notes/ 에서 찾을 것"이라고 한 줄 적기
2. **프로그램 안에 AI(Claude API)를 붙여 조언을 받게 한다면**: `01_TAAS_프로그램규칙_모음.md`를 시스템 프롬프트에 넣고, 질문에 맞는 노트는 `index.json` 태그로 골라서 같이 보내기 (합본 전체는 약 36만 자라 매번 보내기엔 큼)
3. **AI 없이 규칙 엔진으로 만든다면**: `01_TAAS_프로그램규칙_모음.md`의 코드 블록(조건 → 경고 → 처방)을 하나씩 함수로 옮기기

## 쓸 때 지킬 것
- 숫자 임계값 대부분은 **출발값(⚠️)**. 딘 이지스터 1.8 실측이 쌓이면 갱신
- 출처끼리 다를 때 우선순위: **이지스터 1.8 실전 기록(23·47·49·50·52) > 같은 저자 최신 글 > 일반론(라오 등)**
- 이지스터 1.8 단위: 화력 mmAq, 배기 = 댐퍼 10 개방 + 팬 다이얼 (50번 노트)
- 프로젝트에 노트가 추가되면 이 패키지도 다시 뽑아야 최신 상태가 됨
