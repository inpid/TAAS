# TAAS 프로그램 규칙 모음 (노트에서 자동 추출)

- 각 노트의 '프로그램 규칙 / 재생 프로그램 규칙 후보' 섹션만 모은 파일
- 임계값 대부분은 출발값(⚠️) → 딘 이지스터 1.8 실측으로 조정
- 충돌 시 우선순위: 이지스터 1.8 실측(주성현 23·47·49·50·52) > 같은 저자 최신 글 > 일반론(라오 등)



## [01] 로스팅 기초이론 통합 노트 (v1)

- 생두 밀도·경도↑ → 투입온도↓, 초반 화력↑, 배기↑, 드럼↑
- 수분↑ → 초반 구간 길게, 램프업 분할, 탈색 시점 ROR 유지
- 수분↓ → 초반 구간 짧게
- RoR 불안정 → 배기↓
- 컵: 날카로운 신맛·풋내·쪄진 느낌 → 언더(건조 부족) 의심
- 컵: 마른 식물·텁텁·밋밋 → 베이크드 의심
- 컵: 웻 아로마 그을림/어두운 과일 → 풍량 조절
- 후반 풍량↓ → 향↑ 클린컵↓ (트레이드오프)
- 원두 불균일(등급 혼입) → DTR 길게 (게샤 사례 17% → 20~23%)


## [02] 드럼 스피드 현장 코칭 (유튜브)

- 머신별 드럼 변수명 매핑 필요: 기센=Hz, 이지스터=드럼 회전수 값 → 내부적으로 "drum_speed" 하나로 통일, 머신별 스케일은 별도 저장
- 화력을 계속 올려야만 진행이 따라오고 스코칭/색 불균일 → 드럼 속도 부족 의심 → 드럼↑, 가스↓, 투입온도↓
- 드럼↑ 후 진행 시간이 짧아짐 → 가스 추가↓
- 초반 고화력 → 드럼 축열 과다 → 후반 가스를 줄여도 열이 안 빠짐(지연) 경고
- 호퍼 대기 시간 길어짐 → 배치 편차 경고


## [03] ETeRR 로스팅 리뷰 — 에티오피아 두완초 내추럴 × 이지스터 4kg (쇼츠)

- 배치 간 BBP 필수: 쿨다운 → 재예열로 기준 상태 통일 (기준 온도 180℃ 예시)
- 라이트·화려한 내추럴 목표:
  - 초반 배기 낮게(이지스터 20%) → 수분 보호
  - 중반 배기 단계적 상승
  - 1차 크랙 감지 시 배기 크게 상향(이지스터 60%) → 발열 과열 차단
  - 디벨롭 짧게(약 50초, DTR 약 7%대)
- 컵 목표 "클린한 피니시" → 1차 이후 배기↑ 쪽
- 머신별 단위 매핑: 배기 = 이지스터 % / 기센 Pa, 드럼 = 이지스터 회전수 / 기센 Hz


## [04] 빌드업 로스팅 강의 소개 — 윤원균 (아이덴티티 커피랩)

- 생두 입력 변수에 **가공·발효도** 추가 → 스트렝스 레벨 1~4 초기 추정 (무산소/초산발효=1, 일반 내추럴=2, 워시드=3, 뉴크롭 고밀도 게샤 워시드=4, 허니=2~3)
- 초기 샘플은 레벨 3 화력으로 → 컵 평가 후 2 또는 4로 이동
- 투입온도·초반 화력은 레벨과 무관하게 고정, **마이야르 스팟(색 기준) 이후 화력 감소 시작점·폭을 레벨별로 다르게**
- 레벨 1~2: 1차 크랙 전 이전 화력 대비 약 절반까지 선감소 → 1차 발열로 인한 팝콘 현상(표면만 익음, 쓴맛·날카로운 산미·떫음) 예방
- 머신별 마이야르 스팟 온도·도달 시간은 머신 프로필에 저장 (예: W6 155℃·약 4분, W30 160℃·6~7분)
- 계절·생두 온도·환경 변화 시 투입온도 재검토 알림 (8년 고정 공장 사례 방지)
- 각 프로파일에 '의도(발상)' 필드 저장: 목표 로스트 레벨(배경색), 산미·향미·단맛·애프터 흐름


## [05] 데이터 기반 로스팅 가이드 — 케냐 3배치 개선 사례

- 이벤트 자동 감지: 투입(약 7℃ 이상 급락), TP(최저점), 1차(RoR 급락·튐), 배출(재꺾임)
- 1차 이후 RoR 하강 기울기 > 임계값 → "크래시: 전반 열 부족/베이크드 위험" 경고 → 투입온도↓+화력↑ 제안
- 1차 시점 RoR < 머신 기준값 → "초반 과열" 경고 → 초반 최대 RoR↓ 제안 (레벨 3~4 생두에 한정)
- 이전 배치 오버레이 + RoR 차이·온도 차이 수치 표시 → 배출 도달 예측
- 투입온도 탐색은 큰 간격(예: 30℃)으로 시작해 방향 확인 후 좁히기


## [06] 밀도가 다른 두 생두 로스팅 — 스트롱홀드 앰버서더 임지영

- 입력: 밀도(g/L) 자동 분류 — <720 저밀도 / 720~800 보통 / >800 고밀도 (임지영 기준, 머신 무관한 생두 속성)
- 수분·크롭 연차로 밀도 보정 힌트 (패스트 크롭 → 밀도↓)
- 고밀도: 초반 최대 열 → 옐로 이후 '열 추가 장치'(스트롱홀드=교반↓) 사용 → 1차 근접 시 단계적 감소
- 저밀도: 초반 적당 → 옐로 직후 열원 선감소 → 1차 전 더 일찍 감소, 교반 고정
- 화력 변경은 한 단계씩, 조작 횟수 최소화 → 재현성 점수에 반영
- 머신 프로필에 '열을 더 먹이는 수단' 필드: 스트롱홀드=교반↓, 기센=가스/배기, 이지스터=미압/배기/드럼


## [07] 생두 이해 — 품종·산지 방문·분류·당도·가공·커핑 (대담 영상)

- 생두 입력 필드 추가: 품종, 가공(세부 방식·발효 정도), 크롭 연차, 등급(산지별 기준 표기), 브릭스(있으면)
- 내추럴/고당도/고발효 → 로스팅 진행 빠름 경고 (04 레벨 1~2와 연동)
- 품종별 기대 컵노트 템플릿 → 커핑 결과와 비교해 "기대 노트 없음 / 이질 노트" 플래그 (혼입·로스팅 문제 구분용)
- 밀도·수분은 참고값으로만, 투입온도 자동 결정의 단독 근거로 쓰지 않기
- 디펙트 노트(우디·에이지드·리오 등)는 생두 기원 vs 로스팅 기원(스코칭·베이크드) 분리 태깅


## [08] 제주 물 — 수질 데이터와 커피 추출 (딘 경험 + 공식 수질검사)

- 입력 필드: 추출 물(지역·정수장·생수 브랜드), 경도, 알칼리도, TDS
- 기본값: 딘 매장 = 회수정수장 (경도 약 53, TDS 약 137, pH 약 8)
- 경도 < 50 (제주 대부분) → "연수: 추출력 약함" 플래그 → 로스팅 보정보다 레시피·물 보정 우선 제안
- 컵 평가 시 물 조건을 같이 기록해, 로스팅 문제와 물 문제를 분리
- 판매 대상 지역이 다르면(육지·제주 내 다른 정수장) 로스팅 보정 금지 경고


## [09] 제주 물 — 딘 현장 경험 보충 + 매장 필터 선택

- 물 때문에 생긴 맛 문제(산미 소실·뭉개짐)를 로스팅으로 고치려 하면 원두가 왜곡됨 → **커핑은 항상 같은 기준수로**
- 재생 프로그램 규칙 후보
  - 컵 평가에 물 정보(정수장·지하수 여부·TDS·KH·필터 종류) 필수 입력
  - "산미 소실 + 맛 뭉개짐 + 높은 TDS/pH" → 로스팅보다 **물 알칼리도 원인 우선** 플래그, Quell ST류 제안
  - "수율 낮음 + 클린컵 좋음 + 낮은 TDS" → 연수 플래그 (한림권 패턴), Fresh(카본형)·미네랄 보충 제안


## [10] 대회 예선 연습 프로파일 피드백 — 주성현 (Stronghold S7) + 드럼 로스터 해석

- 열원 감소 시 "단일 열원만 남김" 패턴 감지 → 후반 쓴맛 경고 (스트롱홀드: 할로겐 / 드럼: 높은 드럼 축열 + 늦은 가스 감소)
- 1차 직전 화력 변화량 > 임계값 → "급차단: 늘어짐·크래시" 경고
- 같은 생두에서 투입온도 −10℃ → 총 시간 약 +30초 (S7, 0.5kg 브라질 기준) 참고값
- 머신 매핑 표에 스트롱홀드 3열원(열풍/할로겐/드럼히터) + 교반 추가


## [11] 소프트한 생두 3단계 로스팅 — 코스타리카 내추럴 × 이지스터 1.8 (주성현, 180커피)

- 머신 프로필 "이지스터 1.8" 기본 세팅 테이블 (소프트 생두 기준)
  - 라이트: 투입 230℃ / 0.8kPa / 배기 35
  - 미디움: 1kg / 투입 245℃ / 0.7kPa / 배기 30
  - 다크: 800g / 투입 249℃ / 0.6kPa / 배기 20
- 생두 입력: 밀도 + **소프트 포인트(온도·시간)** → 경도 판정 (110℃·2:24 = 소프트)
- 실시간 규칙: RoR 저점 감지 → 상승 전환 감지 시에만 "화력 감소" 알림. 하강 중 감소 시도 시 "베이크드 위험" 경고
- 이전 저점 대비 새 저점이 높으면 즉시 감소 알림
- 조절 폭 자동 제안: 초반 최소 단위 → 수분 손실 진행에 따라 증가
- 감소 후 다음 저점 미형성 → 다음 감소 폭 확대 제안
- 다크 + 소프트 생두 → "미스 위험 높음" 플래그, BT 상승 부족 시 베이크드 경고
- 배기 20 이하 → 채프 끼임 주의 알림


## [12] 스캇 라오(Scott Rao) 핵심 원칙

- RoR 계산: 15초 간격, 과도한 스무딩 금지 (크래시·플릭 감지를 위해)
- **크래시 감지** → "초반 열 부족" 원인 분류 → 다음 배치는 충전온도↑ 또는 초반 가스↑ (1차에서 열 추가 금지)
- **플릭 감지** → "환경 과열·1차 후반" 원인 → 1차 전 ET RoR 상승 경보로 사전 차단
- ET RoR 급상승 → 1차 전 조기 경보
- DTR 목표: 기본 20~25%(라오), 단 출력/투입량 비율이 높거나 아주 약한 라이트면 15% 전후 허용. **배출 결정은 색·BT로**
- 머신 점검 모드: ET 정점 시점 vs 1차 시점 → 풍량 과다/부족 판정 / TP > 1:30 → 프로브 점검 / 드럼 RPM 직접 측정 입력
- BBP 기록 필수 (배출 후 최저 온도, 재가열 시간, 충전 시점)


## [13] 로스팅 실수와 체크포인트 — GSC 생두 업체 영상 (기센 6kg 추정)

- **첫 배치 보정**: 세션 첫 배치면 투입온도 +5℃ 제안 (BBP 미안정 보정)
- 머신 프로필에 "최고 배치 평균 TP"·"옐로 타임 기준" 저장 → 실시간 비교
  - TP가 기준보다 낮음 → "열량 부족" / 높음 → "열량 과다"
  - 옐로 타임이 기준보다 늦음 → "인텐스↓ 예상" 알림, 다음 배치 투입온도↑ 제안
- RoR로 1차 도달 시점 예측 표시 (현재 BT·RoR·머신의 1차 온도로 계산)
- 1차 후 화력 정책은 머신별 설정값으로 (기센 6kg 화자 = 유지 / 이지스터 ETeRR = 배기↑)


## [14] 디카페인 로스팅 잘하는 법 — 아이덴티티커피랩 (쇼츠)

- 생두 가공 = "디카페인" 입력 시 자동 보정
  - 초반 화력 −(머신 단위 1~2단계), 램프업 분할
  - 목표 총 시간 = 일반 프로파일 + 약 1분
  - 목표 디벨롭 = 일반 + 약 30초 (DTR 20~25% 근처)
  - 배기 약간↑ (대류 비중↑), 드럼 RPM 정상 유지
  - "표면 온도 빠른 상승 / 속 미익음" 경고: BT 상승이 빠른데 컵에서 풋내·떫음 → 시간 더 늘리기
- 컵 목표 기본값: 플로럴 극대화가 아니라 단맛·바디·결점 보완


## [15] 월드 커피 로스팅 챔피언십(WCRC) — 대회 구조·우승자 접근법

- "로스트 플랜" 입력 칸: 목표 아로마·플레이버·애프터·산미·단맛·마우스필 (CVA 항목) → 커핑 결과와 일치율 점수화
- 같은 생두 2배치 비교 화면: 디벨롭·색·RoR 차이를 보고 제출(판매) 배치 추천
- 블렌드 도우미: 주력 80% 기본, 선블렌딩/후블렌딩 선택 시 생두별 크랙 시점·밀도 차이 경고
- 결점 분류 학습: 베지털(언더) / 우디·베이크드(크래시·장시간 열 부족) / 로스티(플릭) 태깅

