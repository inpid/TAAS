# 월드 커피 로스팅 챔피언십(WCRC) — 대회 구조·우승자 접근법

- 조사: 2026-10-25 Claude 웹 조사 (모두 의역)
  - [C23] Cropster "2023 World Coffee Roasting Championship" (우승 커브·생두·장비)
  - [C22] Cropster "2022 World Coffee Roasting Competition" (생두 수분·밀도, 결승 3인 인터뷰)
  - [WCC] wcc.coffee 발표 (2025·2026 결과), Daily Coffee News, Beanscene, Barista Magazine
  - [SCA] 2021·2025·2026 규정 변경 공지
  - [P] 팟캐스트·인터뷰 소개글 (2026 브라사르, 2017 미국 챔피언 마크 마이컬슨, 1·2017 가르델리)
- ⚠️ 우승 커브 상세 수치(투입·1차·DTR)는 Cropster 이미지로만 공개돼 글로 판독 불가 → 접근법·생두·블렌드 비율 위주로 정리

신뢰도: ✅ 기존 노트와 일치 · ⚠️ 단일 출처 · ❗ 기존 노트와 충돌

## 1. 대회가 평가하는 것
- 2013년 프랑스 니스에서 시작, 첫 우승은 일본 [WCC]. 2025년 28개 경쟁 단체 참가 예정으로 최대 규모
- 평가 3요소 [C23]
  1. 주어진 생두의 좋은 특성을 살리는 **로스팅 프로파일 설계**
  2. 로스팅한 커피의 **컵 품질**
  3. 사전에 낸 **로스트 플랜(맛 예측)과 실제 맛의 일치도**
- 2017 규정: 챔피언은 "주어진 커피로 최고 품질 로스팅, 생두·원두 평가 능력, 장비 숙련, 계획한 맛에 맞게 로스팅을 설계하고 결과를 정확히 묘사하는 사람"으로 정의
- 생두 평가(그린 그레이딩)는 선수들이 늘 고득점이라 **2021년부터 세계 대회 점수에서 제외** (국가 대회에선 여전히 평가) [SCA]
- 2023년부터 맛 묘사를 **SCA CVA(Coffee Value Assessment)** 방식으로 → ✅ 딘이 이수한 CVA와 같은 체계

## 2. 대회 진행 흐름 [C23]
| 단계 | 내용 |
|---|---|
| 랩 연습·생두 평가 | 스크린 사이즈·밀도·수분·결점 측정. 원산지 정보(국가·지역·농장·고도·품종·가공) 제공 |
| 샘플 로스팅 | 2023 타이베이 기준 **45분, 생두당 사실상 한 번** |
| 샘플 커핑 | 코치와 함께 → **로스트 플랜 제출** (아로마·플레이버·애프터·산미·단맛·마우스필 예측) |
| 연습 로스팅 | 생산 머신·Cropster 연습 (대회 생두 아님, 무득점) |
| 생산 로스팅 ① 싱글 | **30분**, 보통 2배치 → 데이터와 눈으로 보고 1개 즉시 선택 |
| 생산 로스팅 ② 블렌드 | **60분**, 3종 생두 모두 각 10% 이상 사용. 선블렌딩 vs 후블렌딩 선택 |
| 평가 | 커핑 심사 3명 + 비채점 헤드 저지. 점수 대부분이 **커핑 점수 + 묘사 정확도** |
- Cropster의 가스 자동 제어·리플레이 기능은 대회에서 비활성화 [C22]
- 2025: 커피 색 측정·그라인딩 절차 공식화 / 2026: 생두 수량·머신 크기 범위 조정 [SCA]

## 6. 우승자·결승자의 블렌드 전략
| 연도·순위 | 비율 | 방식 |
|---|---|---|
| 2022 1위 펠릭스 | 케냐 80 / 에콰도르 10 / 온두라스 10 | **전부 선블렌딩** — 시간 안전, 섞을 때 실수 방지 |
| 2022 2위 시모 | 동일 계열 | 저품질 둘은 선블렌딩, 고품질 케냐는 따로 → **후블렌딩** |
| 2022 3위 위스누 | 동일 계열 | 중남미는 선블렌딩·길게, 케냐는 따로 짧게 → 후블렌딩 |
| 2023 1위 타우판 | 에티오피아 80 / 코스타리카 10 / 대만 10 | 코스타리카+대만 선블렌딩, 에티오피아 따로 → **후블렌딩** |
| 2023 2·3위 | 동일 비율 | 3종 전부 선블렌딩 |
- 공통: **가장 좋은 생두를 80%로 주력, 나머지는 규정 최소치(10%)**
- 선블렌딩 vs 후블렌딩 모두 우승 → 정답은 없고, 시간·실수 위험·생두 차이로 판단

## 7. 우승자·결승자 인터뷰에서 건진 원칙
### 펠릭스 타이레츠바허 (2022 우승) [C22]
- 싱글(견과류 위주 커피): **언더디벨롭 위험을 피해 잘 익히는 쪽**. 두 배치 중 **디벨롭이 더 긴 첫 배치**를 제출
- 블렌드: 케냐가 먼저 크랙 → 다른 생두 중심부가 언더 안 되게 **조금 더 디벨롭**
- 결점 많은 에코도르는 **로스팅 전 꼼꼼히 핸드픽**
- 대회장 소음으로 크랙 소리를 못 들음 → 데이터·눈으로 판단
- 대회는 커핑용으로 볶았고, 자기 가게라면 에스프레소·필터 용도에 맞춰 다르게 볶겠다고 함
- ✅ 12 라오 "실력만큼만 약하게, 언더를 피하라"

### 시모 크리스티디 (2022 2위, 노르웨이 솔버그&한센) [C22]
- 로스팅 원칙 3기둥: **로스팅 시간, 색 발달, RoR** → 이것을 단계·수치·비율로 세분화
- 평소 노르딕(아주 약한) 스타일인데 대회에선 **마지막 디벨롭을 WCRC 쪽에 맞게 조정**
- 아쉬운 점: 선블렌딩 배치 **쿨링을 5초 늦게** 시작, 다른 배치를 5초 짧게 했으면 → 1~2점 차이 (최종 3점 차로 준우승)
- 대회 컵의 약 80%가 오버로스팅돼 맛이 비슷하다고 봄 → **케냐는 케냐답게, 산지가 구분되는 다양성**을 추구
- ✅ 07 노트 "품종·산지별 기대 컵노트", ✅ 05·12 "변수 하나, 몇 초 차이"

### 위스누 아지 (2022 3위) [C22]
- 중남미 커피는 **너무 빠르지 않게** 볶아 복합성과 산미를 살림
- 같은 블렌드라도 생두별로 시간을 다르게: 중남미 길게, 케냐 짧게 → 후블렌딩으로 균형
- "기계가 다르면 접근도 다르다"

### 마크 마이컬슨 (2017 미국 챔피언, 오닉스 헤드 로스터 출신) [P]
- 우승 로스팅에서 **플릭과 크래시가 다 있었지만** 컵이 훌륭해서 우승
- "커브가 컵을 가르치는 게 아니라 컵이 커브를 가르친다", 정답 프로파일은 없다
- ❗ 12 스캇 라오 "크래시·플릭 = 결점" → 실전에선 컵이 최종 판단. 라오 원칙은 기준선, 판정은 커핑

### 벤자맹 브라사르 (2026 우승, 벨기에 Boo Coffee) [P]
- **유동층(플루이드 베드) 로스터** 사용자 → 기계 종류가 결과를 다르게 만든다는 경험
- 팟캐스트 주제: 낯선 생두 평가, 3종 블렌드 설계, 로스트 플랜·맛 예측, **베지털·우디·베이크드 결점 구분**, "커핑이 로스터의 가장 중요한 기술", "맛에서 뭘 바꿔야 할지 모르면 완벽한 프로파일도 의미 없다", 초라이트 로스팅의 유행이 맛보다 과시가 된 건 아닌지 ⚠️ (소개글 기준, 본편 미청취)

### 미카엘 포르타니에 (2025 우승, 프랑스) [P]
- 바리스타 → 로스터 전향, 커핑의 중요성 강조 (인터뷰 소개 기준)
- 샘플 로스터(ROEST)로 커브를 만들어 생산 로스터로 옮기는 방식 ⚠️

### 루벤스 가르델리 (2017 우승) [P]
- 50g 구리 드럼으로 독학 시작, 지금은 15kg Genio
- **모든 생두를 블라인드로 골라 테이스팅**, 주문받은 만큼만 로스팅
- "커피마다 이상적인 로스트 프로파일은 하나" (추출 방식에 맞추지 않음), 카페 모토 "산미는 죄가 아니다"

### 이안 피코 (2018 미국 챔피언) [P]
- 고밀도 브라질에 **건조 단계를 길게, 마이야르를 충분히** 줘서 단맛·바디·향 복합성 → ✅ 11 주성현 "투입~150℃ 충분한 열", 06 임지영 고밀도 운용
- 세계 대회 준비: 여러 산지를 여러 방식으로 볶고 커핑해 **산지·밀도별 프로파일 라이브러리**를 만들겠다고 함 → ✅ 00 노트 "딘 머신 기준 데이터 수집"과 같은 방법론

## 딘에게 주는 시사점
1. **로스트 플랜 = 맛 예측 정확도**가 점수의 큰 축 → CVA 커퍼인 딘의 강점. 로스팅 전 "이렇게 나올 것"을 적고 커핑으로 맞춰보는 연습이 대회식 훈련
2. **샘플 한 번 → 계획 → 생산 2배치 → 즉시 선택**: 데이터와 원두 색만으로 고르는 판단력이 핵심 → 재생 프로그램의 "배치 선택 보조" 기능 아이디어
3. **블렌드 = 최고 생두 80% + 나머지 최소**: 블렌드 설계 기본값으로 쓸 만함
4. 대회 생두는 고밀도 워시드·내추럴 혼합 → 이지스터에선 11 주성현 하드/소프트 세팅을 둘 다 연습해 둘 것
5. 소음 속 크랙을 못 들어도 판단할 수 있게: **ET RoR·BT RoR·색으로 1차 판정**하는 습관 (12 라오 "ET RoR 조기 경보")

## 재생 프로그램 규칙 후보
- "로스트 플랜" 입력 칸: 목표 아로마·플레이버·애프터·산미·단맛·마우스필 (CVA 항목) → 커핑 결과와 일치율 점수화
- 같은 생두 2배치 비교 화면: 디벨롭·색·RoR 차이를 보고 제출(판매) 배치 추천
- 블렌드 도우미: 주력 80% 기본, 선블렌딩/후블렌딩 선택 시 생두별 크랙 시점·밀도 차이 경고
- 결점 분류 학습: 베지털(언더) / 우디·베이크드(크래시·장시간 열 부족) / 로스티(플릭) 태깅
