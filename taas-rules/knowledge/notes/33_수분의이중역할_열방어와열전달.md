# 수분의 이중 역할 — 열 방어 + 열 전달 (딘 정정·보강)

- 계기: 31 노트(HTST/LTLT)에서 수분을 "열 방어막"으로만 정리 → 딘 지적: **"수분은 열 방어도 하지만 열 전달도 한다"** (2026-10-25)
- 앞으로 모든 노트·레시피·프로그램 규칙에서 수분은 **두 역할을 같이** 고려

---

## 1. 열 전달자로서의 수분 (초반)
- 생두 속 물은 공기보다 열을 훨씬 잘 전도 → 표면에서 받은 열을 **내부로 실어 나르는 매체**
- 수분이 있는 동안 콩 내부 온도가 고르게 오름 → 겉·속 온도 차를 줄임
- 증발할 때 생기는 **수증기**도 콩 내부·드럼 안에서 열을 옮김
- 출처 연결
  - ✅ 01 Prequel "수분은 열전도 매체", "수분이 많을수록 열이 더 깊이 전달"
  - ✅ 20 주성현 "수분은 **초기 열전도체** 역할, 기화에는 막대한 잠열 필요"
  - ✅ 22 소프트포인트 "표면 증발과 내부 수분 이동이 한 팀" → 이 팀플레이가 곧 열 전달 경로
  - ✅ 27 Aero Accel "초기 배기를 낮춰 내부 수분 유지" → 열 전달 매체를 지키는 조작

## 2. 열 방어자로서의 수분 (중후반)
- 수분이 기화하면서 **잠열**로 에너지를 흡수 → 콩 온도가 급하게 오르는 걸 막는 완충
- 수분이 남아 있는 동안 표면 탄화·데미지가 늦게 옴
- 출처 연결
  - ✅ 31 주성현 "다크는 수분을 후반부까지 최대한 가지고 가면서 열에 의한 방어"
  - ✅ 29 "2차 팝은 수분이 거의 사라져 세포가 극도로 약한 상태 → RoR 상승하면 데미지"
  - ✅ 22 "수분은 가소제 → 빠지면 단단·취성"

## 3. 두 역할이 만드는 결론
| 수분이 빨리 빠지면 (HTST·초반 과대류) | 수분이 너무 늦게 빠지면 (열 부족) |
|---|---|
| 열 전달 매체를 일찍 잃음 → **속까지 열이 안 들어감**(박싱·겉속 분리, 22) | 잠열에 에너지를 계속 뺏김 → 진행 지연 → **베이크드**(20) |
| 방어막도 일찍 사라짐 → **후반 데미지·쓴맛** | — |
- 그래서 **초반엔 수분을 지켜 열을 속까지 나르게 하고, 중반엔 충분한 열로 수분을 제때 빼고, 후반엔 남은 수분과 배기로 과열을 막는** 흐름이 이상적
- 이게 주성현 Aero Accel 단계(초기 저배기 → 중반 점진 상승 → 1차 후 상승)와 같은 논리 (27·23)

## 4. 레시피·프로그램 반영
```
[수분 해석 원칙]
- 초반(투입~TP~약 140℃): 수분 = 열 전달자 → 과대류·과열로 표면 선건조시키지 말 것
- 중반(~1차 전): 수분 = 잠열 소비처 → 열 부족 시 지연·베이크드 → 충분한 공급
- 후반(1차~배출, 특히 다크): 남은 수분 = 열 방어막 → 과열 시 빠르게 소실, 데미지

[생두 수분 입력 활용]
- 수분 높음(>=11.5%): 열 전달 매체 많음 + 잠열 많음 → 초반 열은 충분히, 대류는 단계적으로
- 수분 낮음(<=9.5%): 매체·방어막 모두 적음 → 초반 짧게, 후반 과열 경계 강화
```
- 01 Prequel 수분 대응("수분 많으면 탈색 시점 ROR 높게, 램프업 분할 / 적으면 초반 짧게")과 동일 방향
