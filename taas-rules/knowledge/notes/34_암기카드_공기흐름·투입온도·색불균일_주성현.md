# 로스팅 기본기 암기 — 공기 흐름 오해·투입온도 선택·색 불균일 (주성현 블로그 일부)

- 출처 [BL15]: 네이버 블로그 "로스팅패스파인더"(주성현) 글 일부(3~5번 항목, 제목·날짜 캡처에 없음). 본문 안 링크: "로스팅 중 공기의 흐름" (blog.naver.com/rhismine/223471969969, 미확인)
- 딘 메모: **그냥 외우기** → 짧은 암기 카드로 정리

---

## 암기 카드
### ① 공기 흐름은 연기 빼는 장치가 아니다
- 초보는 배기를 연기·가스 제거용으로만 생각 → 스페셜티에선 **로스팅 제어와 맛 조정의 핵심 변수**
- 공기 흐름은 드럼 내부의 열 이동과 커피로의 열 전달에 영향
- **설치 환경마다 설정이 다름** → 로스팅 → 프로파일 확인 → 센서리 확인을 반복하며 찾기 (32 노트: 배관·굴뚝·계절 영향)
- 잘못 쓰면 → **언더디벨롭, 베이크드, 심하면 탐**

### ② 투입온도 선택
| 조건 | 투입온도 |
|---|---|
| **경도가 낮거나, 배출 온도가 높을 때** (소프트·다크) | **높게** 가능 |
| **경도가 높거나, 배출 온도가 낮을 때** (하드·라이트) | **낮게** 필요 |
| 배치 크기가 크게 바뀔 때 | 투입온도도 달라짐 → **배치 크기별 적정 투입온도를 기록**하고 조정 |
- ✅ 11 노트 다크 249℃ / 라이트 230℃ (소프트), 23 노트 하드 라이트 200℃, 22·30 노트 소프트=고온 / 하드=저온

### ③ 색 불균일 = 드럼 속도 점검
- 라이트 로스팅은 얼룩진 외관이 나올 수 있고, 저가 커피는 크기·숙성도 차이로 원래 불균일할 수 있음
- 하지만 **스페셜티에서 원두끼리 색 차이가 크면 드럼 속도가 적절하지 않을 수 있음** → 드럼 속도를 낮추거나 올리면서 **색이 전체적으로 같아지게** 설정
- ✅ 18 노트(이지스터 1.8 75~80rpm), 21 Gear Shift "베드 균일성", 12 라오 "RPM 부적정 = 전도 데미지·불균일"

## 프로그램 규칙 (TAAS 연동용)
```
- 투입온도 제안 = f(경도[soft_point], 목표 배출온도, 배치 크기)
  · soft OR drop_target 높음 → 투입↑ / hard OR drop_target 낮음 → 투입↓
  · 배치 크기 변경 시 → 해당 크기의 과거 투입온도 기록 우선 참조
- 컵·외관 입력 "색 얼룩 큼" (스페셜티 등급) → "드럼 rpm 점검" 제안 (배기·가스보다 먼저)
```
