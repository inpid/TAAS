# 최적의 배치 크기를 찾는 방법 — 효율성과 품질의 균형 (주성현) + 딘 이지스터 1.8 투입량

- 딘 질문: **"1.8 모델인데 최소·최대 몇까지 투입 가능할까?"** → 하단 "딘 이지스터 1.8 투입량" 정리

## 1. 머신 이름과 용량
- 배치 크기 = 한 번에 로스팅하는 커피 양. 로스팅 기계는 보통 드럼 용량이나 최대 배치 크기로 모델명을 정함
  - **기센**: 풀배치일 때 생두 **최대 투입량** 기준
  - **이지스터**: 한 배치 **최대 배출량** 기준
- 모델명 용량이 특정 커피의 이상적 배치 크기를 의미하지는 않음
- 최적 배치 결정 요소: 일일 생산량, 기계 열원·로스팅 배출 포인트, 생두 밀도·경도 등

## 2. 일반적인 기준
- **최대**: 보통 드럼 용량의 **80%** 권장 (5kg 로스터 → 최대 4kg)
- **최소**: 의견이 분분 — 풀배치의 **20%, 25%, 심지어 40%**
- 이런 숫자는 출발점일 뿐, 본인 로스터 경험으로 보완해야 함
- 기계가 열 전달 능력을 제대로 갖추고 잘 관리되면 **전체 용량으로도 충분히** 로스팅 가능
- 글쓴이는 **특정 배출 포인트와 생두 특성**을 기준으로 배치 크기를 결정

## 3. 배치 크기 결정 기준
- 목표 시간: **라이트 8~13분**, 다크는 가능한 한 짧은 시간 → 설정 시간을 준수할 수 있는 크기로
- 생산량: 가능한 최대 배치 사용. 예) **이지스터 4(5kg 용량)에 4.5kg 투입**
- 버너 출력 기준으로 최대 배치를 계산할 수 있음(전통 드럼에 유효, 유체 베드엔 부적용). 계산은 시작점일 뿐 실제 관찰로 조정
- 유체 베드 로스터: 대류로 더 많이 열을 전달하고 섞어줘 큰 배치를 짧은 시간에 처리, 열 손실 적고 티핑·스코칭·페이싱 결함이 적음
- ✅ 12 라오 "로스팅 시간은 투입량 대비 버너 출력 비율로 결정"

## 4. 고정 배치 vs 가변 배치
| | 고정 배치 | 가변 배치 |
|---|---|---|
| 방식 | 동일 크기로 반복 (커피별로 다를 순 있음: 예 라이트 4.5kg / 다크 3kg) | 필요량에 따라 결정. 기계별 기본 범위 안에서 조정 |
| 장점 | 일관성 유지, 변수 제한, 다른 요소를 세밀히 조정 | 로스팅된 커피 양을 세밀히 통제 |
| 단점 | **과잉 생산** (주문 2kg인데 배치 4.5kg면 두 배를 볶게 됨 → 처리 못 하면 비용 부담) | 배치 크기 변경이 다른 모든 요소에 영향 → 추가 조절 필요 |
- 글쓴이 범위 예시
  - **최대 투입 5kg 이지스터4 → 2.5~4.5kg 배치**
  - **최대 투입 700g 스트롱홀드 S7X → 500~700g 배치**
  - 다음 날 추가 로스팅이나 초과분을 카페에서 활용해 조정

## 5. 배치 크기를 늘리거나 줄일 때 (무게 차이 보상)
- 큰 배치는 같은 커피라도 더 많은 에너지 필요
  1. **더 높은 투입온도**: 기계마다 차이는 있지만 **생두 1kg당 투입온도 약 10℃** 조정
  2. **로스팅 전반의 공급 열량↑**
  3. **더 큰 배기값**: 투입량이 많아진 만큼 원활한 대류열을 위해
  4. **전체적으로 길어진 시간**
  5. **배치 간 프로토콜(BBP) 변경**: 작은 → 큰 배치로 전환 시 로스터 내부 열량을 증가
- 큰 → 작은 배치는 위 내용을 반대로
- ✅ 12 라오 "배치 크기 변경은 한 세션에 한 번 이하, 큰→작은 배치 전환 시 BBP 길게"

## 6. 배치 크기 변경 후 일관성 확인
- 로스팅된 커피의 **수분·밀도·색도** 같은 물리적 결과 확인 → 동일한 물리 결과가 나왔는지 (✅ 25 노트 "결과 지표로 일관성 판정")
- 최종 확인은 **커피의 맛**(커핑)

## 7. 큰 배치의 위험
1. **로스팅 결함**: 충분한 열을 주려다 너무 과한 열, 또는 투입량에 비해 부족한 열
2. **컵 불균형**: 대량 배치에서 과한 대류열 → 겉이 속보다 빨리 로스팅되거나, 빠른 공기 흐름으로 겉면이 드라이해져 내부 열전달이 방해(✅ 22 박싱) → 언더. 최적 범위 초과 시 베이크드·언더
3. **기계 손상**: 필요한 열이 로스터 내부 **베어링 그리스를 태울** 수 있음 → 정기 점검·유지보수
4. **화재 위험**: 배치 크기 자체가 직접 원인은 아니지만, 원두가 발화 온도에 도달하면 발생. 연료(원두)가 많을수록 화재가 커질 수 있음. 특히 **다크 로스팅 시 주의**, 큰 배치는 **채프도 많아** 가연성 주의

## 8. 작은 배치의 문제
1. **온도 측정 어려움**: 빈 온도 열전대(프로브)가 **원두 더미에 완전히 잠겨야** 함. 안 그러면 온도 읽기가 부정확 → 맛이 좋아도 재현이 거의 불가능
2. **기계 구조 한계**: 작은 양을 볶으려 버너·공기 흐름을 작게 쓰면, 어떤 기계는 공기 흐름을 너무 낮추면 불꽃에 산소가 부족해 **꺼질** 수 있음

## 9. 반드시 해볼 실험
1. **최대 용량으로 로스팅**: 생두가 충분하면 명시된 최대 용량까지 → 원하는 커브를 따라가는지, 시간이 크게 늘어지는지 확인
2. **배치 크기를 500g~1kg 추가해 로스팅을 느리게**: 프로파일이 마음에 드는데 조금 더 천천히 진행되면 좋겠을 때, 공기·가스를 억지로 조정하는 대신 **배치를 늘려보기** → 기존 배치와 같은 온도·가스·공기 조정으로 변화 관찰
- 평가 기준은 항상 **자신의 입맛**
- 결론: 정답은 없음. 원하는 방식으로 커피를 **일관되게** 로스팅할 수 있는 크기가 정답

## 딘 이지스터 1.8 투입량 (Claude 추정 ⚠️ — 제조사 매뉴얼 확인 필요)
### 추정 근거
1. 이 글: 이지스터는 **최대 배출량** 기준 명명. 이지스터4는 **최대 투입 5kg** → 이름 대비 약 1.25배
   - 같은 비율이면 **이지스터 1.8 최대 투입 ≈ 2.2kg** 안팎
2. 주성현의 이지스터4 운용 범위 2.5~4.5kg = 최대 투입의 **50~90%** → 1.8에 적용하면 **약 1.1~2.0kg**
3. 일반 80% 규칙: 2.2kg × 0.8 ≈ **1.8kg**
4. 실제 기록(같은 기종)
   - 11 주성현: 미디엄 **1kg**, 다크 **800g**
   - 18 주성현: **1kg** (드럼 실험)
   - 05 파이어스코프: 케냐 **1~1.2kg**
   - → **0.8~1.2kg는 실측으로 검증된 구간**

### 정리
| 구분 | 투입량 | 비고 |
|---|---|---|
| 최소 (실용) | **약 0.8kg** | 11 노트 다크 사례로 검증. 이보다 적으면 프로브 잠김 확인 필수 |
| 기본 (딘 시작값) | **1.0kg** | 참고 데이터가 전부 1kg 기준 → 비교·재현이 가장 쉬움 |
| 생산용 | **1.2~1.5kg** | 시간·투입온도 보정 필요 |
| 최대 (추정) | **약 1.8kg** (상한 2.0kg 전후) | 매뉴얼 확인 후 "최대 용량 실험"으로 검증 |
- 배치 변경 시 투입온도 보정 출발값: 1kg당 약 10℃ → **200g 변경 ≈ 2℃**
- 시운전 순서(00 노트)에 **"1kg 기준 배치 → 1.5kg → 최대 용량 실험"** 추가 권장

## 프로그램 규칙 (TAAS 연동용)
```
[머신 프로필 — 이지스터 1.8 (임시)]
- batch_min = 0.8kg, batch_default = 1.0kg, batch_max = 1.8kg (매뉴얼로 갱신)
- batch < batch_min → 경고 "프로브 미잠김 위험: 온도 신뢰도↓"
- batch > batch_max → 차단 "용량 초과: 베어링·화재·불균일 위험"

[배치 크기 변경 보정]
- Δbatch(kg) 입력 시 제안: 투입온도 += 10 × Δbatch (℃), 배기·공급열량↑(증가 시), 예상 시간↑
- 같은 세션에서 배치 크기 2회 이상 변경 → 경고 (12 라오)
- 큰→작은 배치 전환 시 BBP 시간 연장 알림

[고정/가변 배치 모드]
- 주문량 < batch_default 이고 고정 배치 모드 → "과잉 생산" 정보 표시 + 초과분 활용 메모

[다크 + 큰 배치]
- roast_level=dark AND batch >= 0.9×batch_max → "화재·채프 주의" 경고
```
