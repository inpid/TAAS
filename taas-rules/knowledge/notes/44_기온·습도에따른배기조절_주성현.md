# 기온·습도에 따른 로스팅 배기 조절 (주성현)

- 출처 [BL24]: 네이버 블로그 "로스팅패스파인더"(주성현) 2024-08-28. 딘 제공 캡처 1장
- 32 노트(2025-01 계절별 환경 요인)보다 **먼저 쓴 글**. 배기 조절에 초점

신뢰도: ✅ 기존 노트와 일치 · ⚠️ 글쓴이 단독 · ❗ 같은 저자 32 노트와 충돌

---

## 1. 추운 날씨 → 배기를 줄인다
- 추운 날엔 **공기 밀도가 높아져**(부피가 작아져) 로스터 내부의 **열과 수분이 빠르게 빠져나갈** 수 있음
- 이로 인해 로스팅이 예상보다 빨라질 수도 있고(대류열은 공기 속도와 밀접), 로스팅 **후반부엔 열 손실**이 될 수 있음
- → **배기 속도를 줄여** 열 손실을 최소화하고 드럼 내부 열을 안정적으로 유지
- 드럼 내부 수분 제거·증발 속도에도 영향 → 적정 속도를 설정해 일관된 맛 유지
- ✅ 32 노트 "겨울: 외기가 차가우면 굴뚝 효과로 배기 속도가 빨라질 수 있음" → 같은 배기 설정이 겨울엔 더 세게 작동하므로 **설정값을 낮춤**

## 2. 더운 날씨 → 배기를 늘린다
- 더운 날엔 **공기 밀도가 낮아져**(부피가 커져) 열과 수분이 **쉽게 빠져나가지 않음**
- 로스팅 후반에 내부 온도가 **과도하게 올라갈** 위험
- → **배기 속도를 높여** 축적되는 수분과 과열된 열을 배출, 균형 잡힌 로스팅
- ✅ 32 노트 "여름: 외기가 높으면 배기 속도가 느려질 가능성" → 보정으로 **설정값을 높임**

## 3. 습도
| 상황 | 이 글(2024-08) | 대응 |
|---|---|---|
| **높은 습도** | 공기 중 수분이 **열 전달을 방해** → 로스팅이 느려지거나 불균일. 또 생두 수분이 높아져 더 많은 에너지 필요 → 시간 길어짐 | **배기↑**로 내부 습기를 배출, 열 전달 최적화 |
| **낮은 습도** | 열 전달이 **매우 빠르게** → 예상보다 빨리 진행, 과도한 가열·탄맛 위험 | **배기↓**로 너무 빠르지 않게 |

### ❗ 32 노트(2025-01, 같은 저자)와 정반대
- 32: "습도↑ → 챔버 **열전달 효율 증가** → 투입온도↓" / "습도↓ → 열전달 느림 → 투입온도↑"
- 44(이 글): "습도↑ → 열전달 **방해**·생두 수분↑ → 느려짐 → 배기↑" / "습도↓ → 빨라짐 → 배기↓"
- 그래피티 노트: "습도 1%↑ → 생두 수분 약 0.18%↑" → **이 글(44) 쪽과 같은 방향**
- 정리(Claude): 습도는 두 경로로 작용
  1. **생두 흡습 경로**(보관 중 생두 수분↑ → 잠열·에너지 수요↑ → 진행 느림) — 그래피티·44
  2. **공기 경로**(습한 공기의 열 운반 특성) — 32
  - 제주처럼 습도가 높고 생두를 매장에 보관하는 환경에서는 **1번(생두 수분 증가)의 영향이 더 클 가능성**이 높다고 봄 → **기본 가정은 44 방향**(습하면 느려짐)으로 두고, 배치 전 생두 수분 실측으로 확인
  - 33 노트 "수분 = 열 전달 + 열 방어(잠열)": 생두 수분이 늘면 초반 열 전달은 좋아지지만 잠열 소비가 커서 **전체 진행은 느려지는** 쪽이 일반적

## 4. 결론
- 기온과 습도에 따른 배기 속도 조절은 로스터의 **핵심 역량** 중 하나. 이를 고려해 배기 속도를 세밀하게 조절하면 일관된 품질

## 딘 매장(제주 중문) 배기 보정 출발값
| 상황 | 배기 | 그 외 |
|---|---|---|
| 겨울 (차가운 외기, 굴뚝 효과↑) | 평소 단계값보다 **한 단계 낮게** | 32: 투입·종료 온도 약간↑ |
| 여름 (덥고 습함) | 평소보다 **한 단계 높게** (1차 후 클린업 강화) | 32: 투입·종료 온도 약간↓, 제습 50~60% |
| 장마·습한 날 | 배기↑ + **생두 수분 측정** | 수분이 평소보다 높으면 초반 열 충분히 (33) |
| 건조한 날 | 배기↓ | 진행이 빨라지면 투입 약간↓ |
- ⚠️ "한 단계"는 Aero Accel 단계값(예: 이지스터 Pa 기준 5Pa 안팎) 출발값 → 딘 데이터로 조정

## 프로그램 규칙 (TAAS 연동용, 32 노트 규칙 보완)
```
[배기 계절 보정]
- outdoor_temp <= 8 → 배기 스케줄 전체 −1 step 제안 ("차가운 공기: 열·수분 손실 빠름")
- outdoor_temp >= 28 → 배기 스케줄 +1 step 제안 ("더운 공기: 후반 과열·습기 축적")
- room_humidity >= 70 → 배기 +1 step + "생두 수분 측정" 요청
- room_humidity <= 40 → 배기 −1 step

[습도 방향 판정 (데이터 학습)]
- 같은 랏·같은 세팅 배치들에서 room_humidity 와 (TP 시간, 1차 시간, 총 시간) 상관 계산
  → 양의 상관(습할수록 느림)이면 44 모델, 음의 상관이면 32 모델로 딘 매장 기본값 확정
```
