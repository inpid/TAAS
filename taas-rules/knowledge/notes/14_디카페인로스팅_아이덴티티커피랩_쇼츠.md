## 1. 디카페인 생두의 특성 (화자 설명)
- 열은 많이 받는데, 열을 만났을 때 커피 성분이 잘 녹아 나오지 않음 🔍
- 같은 화력을 쓰면 디카페인은 **표면 온도가 빠르게 올라감** — 무르기 때문
- 그래서 전체 로스팅은 빨라지는데 **속까지 열전달이 안 됨** → "온도는 오르는데 속이 안 익는 느낌"
- ✅ 그래피티 노트 "디카페인은 화상 입은 피부처럼 겉 표면이 벗겨져 있어 오염·산화가 빠르다"와 같은 맥락(표면이 약함)
- ❗ 그래피티 노트 "로스팅 방법 자체는 일반 생두와 같다" → 이 영상은 **다르게 볶아야 한다**고 봄

## 2. 핵심 팁: 길게, 고르게
1. **로스팅을 길게 가져갈 것**
   - 평소 디카페인 프로파일이 8분이면 → **약 1분 늘린다**고 생각
2. **화력을 초반에 확 올리지 말고 넓게 펴서 분배**
   - 시연: 로스팅 시간을 늘리려고 화력을 줄이고, 할로겐도 5 정도로 더 낮춤
3. **고르게 속까지 익히는 게 포인트** — 탄 맛으로 디카페인 맛을 가리려 하지 말 것
4. **디벨롭 타임도 기존보다 길게**
   - 예: 평소 1분 디벨롭이면 → **약 30초 더** (1:30)
5. 목적: 디카페인으로 극한의 플로럴을 만드는 게 아니라, **디카페인 특유의 맛과 성분이 잘 안 우러나는 단점을 가리는 것**
   - 그래서 **대류 열량을 많이 쓰고**, 디벨롭·총 시간을 늘려 보완

## 3. 기존 노트와의 관계
- ✅ 12 스캇 라오 "베이크드는 느린 로스팅이 아니라 RoR 크래시가 원인" → 시간을 늘려도 RoR이 꾸준히 내려가면 문제없다는 근거
- ✅ 01 Prequel "대류열 = 오븐: 전체적으로 고르게 익고 표면 캐러멜화가 덜 진행", "크고 무를수록 약한 열량"
- ✅ 04 윤원균 스트렝스 레벨: 디카페인은 표면이 빨리 오르는 무른 생두 → 초반 열을 적게(레벨 1~2 쪽 운용)
- ❗ 11 주성현 "투입~140~150℃에 열을 최대로" → 디카페인은 예외로 초반 고화력을 피함. 주성현도 "소프트 커피는 열량을 적게 쓰고 투입온도를 높인다"고 했으므로, **초반 '가스'는 낮추되 투입온도나 대류로 속까지 열을 넣는** 방향이면 충돌이 줄어듦 (Claude 해석)
- ❗ 03 ETeRR·04 레벨 2 "디벨롭을 짧게 끊어 향 보존" → 디카페인은 반대로 디벨롭을 늘림. 목표가 플로럴이 아니라 결점 보완이라 방향이 다름

## 4. 드럼 로스터(이지스터·기센)로 옮기면 ⚠️ Claude 해석
| 스트롱홀드에서 한 일 | 드럼 로스터로 |
|---|---|
| 할로겐(복사) 낮춤, 초반 화력 확 올리지 않음 | 초반 가스를 평소보다 낮게 시작, 램프업을 여러 단계로 완만하게 (01 Prequel 수분 파트의 "램프업 분할"과 같은 기법) |
| 대류 열량을 많이 씀 | 배기(풍량)를 평소보다 조금 높게 유지해 공기로 고르게 익힘. 드럼 RPM은 정상 범위 유지 (12 라오: 낮은 RPM = 전도 데미지) — 전도로 표면만 타는 걸 피함 |
| 총 시간 +1분 | 8분 → 약 9분. 단 RoR은 끝까지 꾸준히 하강해야 함 (크래시 나면 베이크드) |
| 디벨롭 +30초 | 1:00 → 약 1:30. 라오 DTR 20~25% 범위로 수렴 |
| 탄 맛으로 가리지 않음 | 배출 색으로 판단, 2차 진입으로 맛을 덮는 방식은 피함 |
- 디카페인은 표면이 이미 약해 **산화가 빠르다**(그래피티 노트) → 로스팅 후 숙성·소진 기간도 일반 원두보다 짧게 잡는 게 안전 ⚠️

## 재생 프로그램 규칙 후보
- 생두 가공 = "디카페인" 입력 시 자동 보정
  - 초반 화력 −(머신 단위 1~2단계), 램프업 분할
  - 목표 총 시간 = 일반 프로파일 + 약 1분
  - 목표 디벨롭 = 일반 + 약 30초 (DTR 20~25% 근처)
  - 배기 약간↑ (대류 비중↑), 드럼 RPM 정상 유지
  - "표면 온도 빠른 상승 / 속 미익음" 경고: BT 상승이 빠른데 컵에서 풋내·떫음 → 시간 더 늘리기
- 컵 목표 기본값: 플로럴 극대화가 아니라 단맛·바디·결점 보완
