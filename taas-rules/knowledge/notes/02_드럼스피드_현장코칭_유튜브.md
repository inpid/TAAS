# 드럼 스피드 현장 코칭 (유튜브)

- 출처 [YT1]: https://www.youtube.com/watch?v=3jiQhpODb3Y (자막 3:29~12:43 구간, 딘 제공 스크립트)
- 형식: 로스터리 현장 방문 코칭 대화. 영상 제목·채널·출연자는 미확인
- **머신: 이지스터(Easyster)** (딘 확인). "스마트"는 이지스터 모델/옵션명(업그레이드 약 1천만 원 언급), "기어 시프트"·"에어 엑셀"도 이지스터 쪽 용어
- 배치: 20kg 배치 대상 코칭, 비교로 30kg·4kg 언급
- 자동 자막이라 단어 오인식 있음 ("화약/활약"=화력, "크랩"=크랙, "연량"=열량, "589"=58~59)

## 용어 정리 (딘 확인)
- 영상의 드럼 숫자(37 → 55 → 57~59)는 **이지스터의 드럼 회전수 값**
- 기센에서는 같은 개념을 **Hz(드럼 스피드)**로 표기 → 머신마다 단어·스케일이 다를 뿐 "드럼 회전 속도"라는 같은 변수
- 주의: 이지스터 숫자를 기센 Hz 숫자로 그대로 옮기면 안 됨 (스케일이 다름). 비교는 "기존 대비 얼마나 올렸나"의 방향·비율로 할 것

신뢰도: ✅ 기존 노트(01)와 일치 · ⚠️ 이 영상 단독 · ❗ 기존 노트와 충돌

## 1. 문제 진단: 드럼 회전수가 너무 낮음
- 증상: 로스팅이 늘어짐 → 로스터가 화력을 계속 올림 → 드럼이 과열 → 스코칭(바닥에 붙은 콩이 그을림), 색 불균일
- 원인 논리: 드럼이 느리면 콩이 공중에 뜨는 횟수가 줄어 열을 제대로 공급받지 못함. 바닥에 붙어 있는 콩이 많아짐
- 기존 설정: 드럼 37(→39 언급) = "너무 느리다"
- ✅ Prequel의 "낮은 드럼 스피드·덜 띄우는 교반 = 전도열↑"과 일치, 프라이팬 비유(표면 캐러멜화↑·편차)와도 일치

## 2. 수정 처방 (이지스터 20kg 배치)
| 항목 | 기존 | 1차 수정 | 2차 권장 |
|---|---|---|---|
| 드럼 회전수 | 37 | 55 | 57~59 |
| 가스(화력) | 더 높음 | 낮춤(48) | 47~48 |
| 투입 온도 | 더 높음 | 260℃ | 250℃ |
| 투입량 | — | — | 줄임 |
- 결과: BT 상승 속도가 이전 배치보다 빨라짐(더 적은 열로도). 그래프가 튀거나 올라갔다 떨어지는 현상 없이 안정적, 색이 더 고름
- 원칙: 드럼을 올려 열 공급 효율을 높였으니 굳이 강한 화력이 필요 없다 → **드럼↑ + 가스↓**
- 판단 기준: 바꾼 뒤 시간이 기존 수준이면 OK, 더 짧아지면 화력을 더 줄인다
- 20kg이면 12~13분대가 나와도 시간 자체는 상관없음. 중요한 건 **진행의 안정성**(=커피가 데미지를 안 받는 진행)
- 컬러: 결과 다크 쪽 색도 53 언급(측정기·스케일 미확인)

## 3. 핵심 원리 ⚠️(논리는 타당, 출처 단독)
- 열풍은 가스를 줄이면 즉시 줄지만, **드럼은 가스를 줄여도 바로 식지 않는다** (축열)
- 그래서 초반 가스를 강하게 쓰면 과열된 드럼으로 로스팅이 진행 → 결점 확률↑
- 적정 화력이어도 드럼이 느리면 커피는 열을 덜 받는다. 그렇다고 화력을 너무 낮추면 총 열량 부족 → 적정 화력 기준을 잡고 맛으로 테스트
- 한 번에 한 변수만 바꿔 비교 (이 코칭에서도 드럼 회전수만 먼저 변경)

## 4. 투입 루틴: 호퍼 대기 시간
- 생두를 호퍼에 오래 올려두지 말 것 → 예열된 머신 위에서 맨 아래 생두 온도가 많이 올라가 배치가 달라짐
- 30kg: 투입 온도 도달 약 5~6℃ 전에 호퍼에 올리고 바로 투입
- 4kg: 약 0.5℃ 전에 올림
- ⚠️ 정확한 숫자는 자막 인식 불안정

## 5. 기타 주장
- 그래프가 안정적으로 뽑힌 커피가 상미 기간(셸프라이프)도 더 길다 ⚠️ (경험적 주장, 근거 미제시)
- 같은 매장의 다른 프로파일들도 대부분 드럼이 느려 같은 문제가 있었음 → 드럼부터 전반적으로 올리라는 처방

## 기존 노트(01)와의 관계
- ✅ 드럼↑ = 대류↑, 고른 가열 (Prequel 열 전달)
- ✅ 경도 높은 생두 → 드럼 빠르게 (180, 기센 Hz 기준)
- ❗ 180의 "다크 로스팅 = 드럼 느리게·적게 투입"과 부분 충돌: 이 영상은 다크(색도 53) 배치에서도 드럼을 크게 올렸음. 단 "투입량 줄임"은 일치. → 대용량(20kg)에서 드럼이 지나치게 느린 경우는 로스트 레벨과 무관하게 스코칭 위험이 우선, 으로 해석 가능 (검증 필요)

## 재생 프로그램 규칙 후보
- 머신별 드럼 변수명 매핑 필요: 기센=Hz, 이지스터=드럼 회전수 값 → 내부적으로 "drum_speed" 하나로 통일, 머신별 스케일은 별도 저장
- 화력을 계속 올려야만 진행이 따라오고 스코칭/색 불균일 → 드럼 속도 부족 의심 → 드럼↑, 가스↓, 투입온도↓
- 드럼↑ 후 진행 시간이 짧아짐 → 가스 추가↓
- 초반 고화력 → 드럼 축열 과다 → 후반 가스를 줄여도 열이 안 빠짐(지연) 경고
- 호퍼 대기 시간 길어짐 → 배치 편차 경고
